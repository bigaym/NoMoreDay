## 1. 设计哲学 (Design Philosophy)

在 **NoMoreDay** 中，怪物词缀不仅仅是数值的提升，它们必须改变玩家的**战术决策 (Tactical Decision)**。

1.  **高可视性 (High Readability)**：玩家应该能在 0.5 秒内通过视觉特效（而非文字标签）识别出怪物的威胁。我们将利用 GPU 粒子和 Shader 描边来实现这一点。
2.  **组合效应 (Synergy)**：词缀之间应能产生化学反应。例如，`[Fast]` (快速) + `[Molten]` (熔火) 会让怪物变成一个移动的烈焰路径生成器，极大增加走位压力。
3.  **反制玩法 (Counter-Play)**：每个词缀都应有明确的应对手段。`[Shield]` 防止远程伤害 -> 必须近身；`[Explode]` 死亡爆炸 -> 必须远离。

## 2. 词缀分级与生成 (Tiers & Generation)

基于 ECS 架构，词缀本质上是附加在实体上的 **Components** 或 **Tags**。

| 稀有度 (Rarity) | 颜色 | 词缀数量 | 组成规则 | 同屏上限 |
| :--- | :--- | :--- | :--- | :--- |
| **Magic (魔法)** | 蓝色 | 1 | 1 Suffix (数值/简单机制) | 50+ |
| **Rare (稀有)** | 金色 | 2-3 | 1 Prefix (核心机制) + 1-2 Suffixes | 10 |
| **Unique (传奇)** | 橙色 | 3-4 | 专属 Unique Mechanic + 2-3 Hybrid | 1 |
| **Nemesis (宿敌)**| 红色 | 动态 | 进化型词缀 (Evolution Traits) | 1 (Map Globle) |

## 3. 词缀库详解 (Affix Library)

### 3.1 元素附魔类 (Elemental Infusions)
*作为 Prefix 或 Suffix 出现，改变怪物伤害类型并增加抗性。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 实现逻辑 (Impl Note) |
| :--- | :--- | :--- | :--- |
| **Molten (熔火)** | 攻击造成额外火伤；死亡及移动时留下伤害火径。 | 通体红色发光，脚下拖曳 GPU 粒子火径。 | `Position` 变化时在 `HazardMap` 注册伤害区域。 |
| **Frozen (极寒)** | 攻击附带 20% 减速；周围 300px 产生冰缓光环。 | 蓝色冰霜描边，周围地面有冰霜 Shader。 | `AuraComponent` 周期性给周围玩家加 `Slow` Debuff。 |
| **Storm (雷暴)** | 周期性召唤落雷打击玩家位置；受击 10% 几率释放电弧。 | 黄色电流缠绕，头顶有积雨云图标。 | `TimerComponent` 触发 `LightningStrike` 技能。 |
| **Toxic (剧毒)** | 攻击叠加中毒层数；死亡后留下毒爆云。 | 绿色粘液滴落特效，死亡产生绿色烟雾。 | `OnDeath` 事件触发 AOE 伤害池。 |
| **Void (虚空)** | 攻击造成 5% 最大生命值的真实伤害（无视护甲）。 | 紫色扭曲 Shader，攻击带黑色拖尾。 | 修改 `DamagePipeline`，添加 `TrueDamage` 标签。 |

### 3.2 进攻增强类 (Offensive Modifiers)
*通常作为 Suffix，强化怪物的杀伤力。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 实现逻辑 (Impl Note) |
| :--- | :--- | :--- | :--- |
| **Fast (疾风)** | 移速 +50%，攻速 +30%。 | 身体带残影 (Motion Blur)。 | 直接修改 `Velocity` 和 `CombatStats`。 |
| **Accurate (鹰眼)** | 射程 +50%，且投射物会追踪玩家。 | 眼睛部位高亮红光。 | 投射物添加 `HomingComponent`。 |
| **Multi-Shot (多重)** | 远程投射物数量 +2 (呈扇形)。 | 发射时有额外枪口闪光。 | 修改 `SkillSystem` 的发射逻辑。 |
| **Vampiric (吸血)** | 造成伤害的 50% 转化为自身生命值。 | 攻击命中时有红色血球飞回。 | `DamagePipeline` 结算阶段触发 `Heal`。 |
| **Berserker (狂暴)** | 生命值 < 50% 时，体型变大，伤害翻倍。 | 身体变红且膨胀 (Scale Up)。 | `Update` 中检测 HP，动态调整 Scale 和 Dmg Mult。 |

### 3.3 防御与机制类 (Defensive & Utility)
*通常作为 Prefix，改变玩家的击杀策略。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 实现逻辑 (Impl Note) |
| :--- | :--- | :--- | :--- |
| **Shielding (护盾)** | 周期性给周围友军施加无敌护盾 (持续 2s)。 | 自身周围有金色气场连接友军。 | AI 行为树增加 `CastShield` 节点。 |
| **Teleporter (闪烁)** | 受击或每隔 5s 瞬移到玩家身后。 | 闪烁残影，伴随空间撕裂音效。 | 检查 `LineOfSight` 和距离，强制设置 `Position`。 |
| **Mirror Image (镜像)** | 生命值 < 50% 时分裂出 2 个幻象 (10% HP, 100% Dmg)。 | 瞬间模糊并分裂。 | `Instantiate` 新实体，继承 AI 但 HP 极低。 |
| **Nullifier (消魔)** | 攻击命中时驱散玩家身上的 Buff (如护盾、加速)。 | 攻击带白色破魔光效。 | 命中回调中移除玩家 `BuffComponent`。 |
| **Avenger (复仇者)** | 视野内每死一个友军，自身伤害+10%，体型+5%。 | 友军死亡时吸收灵魂特效。 | 监听全局 `EntityDeath` 事件或区域统计。 |
| **Waller (筑墙)** | 在玩家周围生成 U 型土墙，限制走位。 | 地面升起岩石模型。 | 动态修改 `GridMap` 阻挡信息。 |

## 4. 致命组合 (Deadly Combinations)

在生成稀有怪物时，应避免无意义的随机，尽量权衡“协同效应”。

1.  **" The Meat Grinder" (绞肉机)**:
    *   **Fast (疾风)** + **Molten (熔火)**
    *   **体验**: 怪物像疯狗一样追着玩家跑，同时在身后铺满火径。玩家如果一味后退会被烧死，必须侧向风筝。

2.  **" The Sniper Squad" (狙击小队)**:
    *   **Frozen (极寒)** + **Multi-Shot (多重)**
    *   **体验**: 一次射出多发冰箭，只要中一发就会减速，导致后续更容易中箭。极具压迫感。

3.  **" The Undying Mob" (不死军团)**:
    *   **Shielding (护盾)** + **Avenger (复仇者)**
    *   **体验**: 护盾怪保护小怪，玩家被迫通过走位先杀护盾怪。如果强杀小怪，护盾怪会因为复仇者词缀变得无法处理。

## 5. 技术实现细节 (Technical Implementation)

### ECS 组件结构

我们需要将词缀抽象为轻量级的 Tags 或 Components，以便 Systems 处理。

```cpp
// 词缀数据组件
struct AffixComponent {
    std::vector<AffixID> prefixes;
    std::vector<AffixID> suffixes;
};

// 运行时状态 (用于处理冷却、累积值等)
struct AffixStateComponent {
    float teleportCooldown;
    float shieldCooldown;
    float moltenTickTimer;
    // ... 使用 union 或 std::variant 节省内存
};
```

### 渲染优化

*   **Shader Overlay**: 不要给每种词缀做独立贴图。使用 Shader 在原贴图上叠加一层颜色（Outline 或 Tint）。
*   **GPU Particles**: Molten、Toxic 等地面效果应完全使用 Compute Shader + SSBO 处理，避免 CPU 生成大量实体。
