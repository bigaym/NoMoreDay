# 2D 暗黑Like Roguelite - 怪物词缀设计 (Monster Affixes Design)

**Version:** 2.0 (Enhanced)
**Status:** Approved
**Author:** Designer Agent
**Ref:** Path of Exile, Diablo 4, Last Epoch

---

## 1. 设计哲学 (Design Philosophy)

在 **NoMoreDay** 中，怪物词缀不仅仅是数值的提升，它们必须改变玩家的**战术决策 (Tactical Decision)**。

1.  **高可视性 (High Readability)**：玩家应该ne能在 0.5 秒内通过视觉特效（而非文字标签）识别出怪物的威胁。我们将利用 GPU 粒子和 Shader 描边来实现这一点。
2.  **组合效应 (Synergy)**：词缀之间应能产生化学反应。例如，`[Vortex]` (漩涡) + `[Volatile]` (易爆) 会强制将玩家拉入即将爆炸的危险区域。
3.  **反制玩法 (Counter-Play)**：每个词缀都应有明确的应对手段。
    *   `[Proximity Shield]` 防止远程伤害 -> 必须近身。
    *   `[Volatile]` 死亡爆炸 -> 必须远离。
    *   `[Mana Siphon]` 资源燃烧 -> 必须站在安全环内或快速击杀。

## 3. 核心词缀库 (Affix Library)

### 3.1 元素与环境类 (Elemental & Environmental)
*改变战场环境，迫使玩家移动。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 反制 (Counter-Play) |
| :--- | :--- | :--- | :--- |
| **Molten (熔火)** | 移动时留下燃烧地面 (DoT)；死亡后产生延迟爆炸。 | 通体红光，脚下拖曳 GPU 火径。 | 不要追尾；不要站在尸体上。 |
| **Frozen (极寒)** | 周期性生成跟随玩家的冰霜球，爆炸造成冻结。 | 蓝色冰霜描边，空中悬浮冰球。 | 保持移动，不要在球体停止时停留。 |
| **Storm Strider (雷行)** | 受到攻击时在自身周围产生闪电幻影，延迟造成电击。 | 黄色电流缠绕，留下带电残影。 | 击打后立即移动，避免站桩输出。 |
| **Toxic (剧毒)** | 攻击叠加中毒；死亡生成 3 个追踪毒球 (Volatile Orbs)。 | 绿色粘液滴落，死亡时绿色爆裂。 | 击杀后立刻闪避毒球。 |
| **Void Zone (虚空)** | 周期性在玩家脚下生成黑洞区域，造成真实伤害。 | 紫色扭曲 Shader，地面黑色圆圈。 | 看到地面圆圈立即移出。 |

### 3.2 阻断与控制类 (Crowd Control & Denial)
*限制玩家行动或资源，打破“割草”节奏。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 反制 (Counter-Play) |
| :--- | :--- | :--- | :--- |
| **Vortex (漩涡)** | 每 5 秒将半径 400px 内的玩家拉向自身。 | 身体周围有旋风扭曲特效。 | 留好位移技能在拉扯时使用。 |
| **Waller (筑墙)** | 在玩家周围生成 U 型土墙，限制走位。 | 地面升起岩石模型。 | 使用穿墙技能或绕行。 |
| **Mana Siphon (虹吸)** | 周围有一圈蓝色光环，**只有光环内圈安全**。外圈持续燃烧魔法值。 | 巨大的蓝色圆环，中间空心。 | 必须贴脸近战，或者站在极远处。 |
| **Suppressor (压制)** | 开启护盾时，免疫/高额减免来自圈外的远程投射物伤害。 | 红色半透明球形罩子。 | 必须进入罩子内部输出 (Face-tank)。 |
| **Entangler (纠缠)** | 攻击命中施加“定身”藤蔓 (无法移动，可攻击)。 | 绿色藤蔓缠绕玩家腿部。 | 使用位移技能打破藤蔓。 |

### 3.3 进攻增强类 (Offensive Modifiers)
*强化怪物杀伤力，惩罚失误。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 反制 (Counter-Play) |
| :--- | :--- | :--- | :--- |
| **Fast (疾风)** | 移速/攻速 +50%。 | 身体带残影 (Motion Blur)。 | 利用减速/冰冻控制，避免被围。 |
| **Multi-Shot (多重)** | 投射物数量 +4 (呈扇形或环形)。 | 发射时有额外枪口闪光。 | 侧向走位躲避弹幕。 |
| **Homing (追踪)** | 投射物会缓慢转向追踪玩家。 | 投射物带红色眼睛特效。 | 引导投射物撞墙。 |
| **Soul Eater (噬魂)** | **每有一个单位(敌/友)在附近死亡**，体型+5%，攻速+5%。 | 身上有灵魂被吸入的特效，越来越大。 | 优先击杀，不要先杀小怪养肥它！ |
| **Berserker (狂暴)** | 生命值 < 50% 时，体型变大，伤害翻倍，免疫控制。 | 身体变红且膨胀 (Scale Up)。 | 留爆发技能在半血后秒杀。 |

### 3.4 防御与机制类 (Defensive & Utility)
*改变击杀策略。*

| 词缀名 (Name) | 效果 (Mechanic) | 视觉表现 (Visual Cue) | 反制 (Counter-Play) |
| :--- | :--- | :--- | :--- |
| **Shielding (护盾)** | 周期性给周围友军施加无敌护盾 (连接线)。 | 金色光束连接周围怪物。 | 必须先杀本体 (护盾发生器)。 |
| **Teleporter (闪烁)** | 受击或定时瞬移到玩家身后发动攻击。 | 闪烁残影，空间撕裂音效。 | 预判瞬移位置，反向施法。 |

## 4. 致命组合 (Deadly Combinations)

系统生成稀有怪时，应尝试构建协同效应 (Synergy)。

1.  **"The Black Hole" (黑洞炸弹)**:
    *   **Vortex (漩涡)** + **Molten (熔火) / Volatile (易爆)**
    *   **机制**: 先把玩家吸过来，然后自身爆炸或脚下生成火海。
    *   **体验**: 强制位移 + 爆发伤害，极其致命。

2.  **"The Anti-Range Bunker" (远程克星)**:
    *   **Suppressor (压制)** + **Teleporter (闪烁)**
    *   **机制**: 远程打不动罩子，怪还会直接瞬移脸骑脸。
    *   **体验**: 迫使远程职业必须具备近战应对能力或高机动性。

3.  **"The Snowball" (雪球效应)**:
    *   **Soul Eater (噬魂)** + **Summoner (召唤)** / **Mirror Image (镜像)**
    *   **机制**: 召唤出的小怪或幻象死亡后，本体变得极强。
    *   **体验**: 错误的击杀顺序会导致造出一个 Boss 级的怪物。

4.  **"Resource Starvation" (资源枯竭)**:
    *   **Mana Siphon (虹吸)** + **Fast (疾风)**
    *   **机制**: 快速贴身燃烧你的蓝量，导致无法释放位移技能逃跑。
    *   **体验**: 软控制导致的死亡，非常考验走A技巧。

## 5. 宿敌进化系统 (Nemesis Evolution)

宿敌是地图的最终威胁，它会根据玩家的**行为历史**进行针对性进化。

### 5.1 伤害类型适应 (Adaptive Resistance)
*   系统记录玩家造成伤害的类型分布 (e.g., 80% Fire, 20% Phys)。
*   **进化**: 宿敌生成时获得 `[Fire Resistance]` + `[Elemental Plating]` (受元素伤害降低)。

### 5.2 行为模式适应 (Behavioral Adaptation)
*   **Kiting Punisher (针对风筝流)**:
    *   若玩家平均与怪距离 > 400px。
    *   **进化**: 获得 `[Teleporter]` (闪烁) 或 `[Harpoon]` (钩子，将玩家拉过来)。
*   **Burst Counter (针对爆发流)**:
    *   若玩家平均击杀时间 < 1s 或造成极高爆发伤害。
    *   **进化**: 获得 `[Phase Shield]` (相位护盾：受到爆发伤害超过30%血量时，强制无敌 2s，有冷却)。
*   **Tank Buster (针对坦克流)**:
    *   若玩家平均承受伤害极高。
    *   **进化**: 获得 `[Sunder]` (叠加破甲) 或 `[Void Touch]` (造成 % 最大生命值的真实伤害)。

## 6. 技术实现细节 (Implementation Notes)

### 6.0 UMR 并轨约束（2026-03-01）

1. 怪物词缀的**属性修饰**统一走 `UMR`：`MonsterModifierAdapter -> ModifierEvaluator -> AttributePipeline`。
2. 怪物词缀的**行为机制**（OnHit/OnDeath/Update）暂保留 `MonsterAffixSystem`，禁止功能回退。
3. 新增怪物词缀必须显式声明属于“属性修饰”还是“行为机制”；属性修饰优先落 `assets/data/modifier_v2/monster_modifiers.json`。
4. 过渡期禁止在 `AttributePipeline` 新增怪物词缀 `switch/case` 旁路。
5. 行为机制接线约束：OnUpdate/OnHit/OnDeath 的触发门禁统一走 UMR 事件 Op 桥（`MonsterModifierAdapter` + `ModifierEvaluator`），行为处理器继续留在 `MonsterAffixSystem`。
6. 分阶段并轨进度：`Molten`、`Teleporter`、`Frozen`、`Berserker`、`VoidZone`、`ManaSiphon`、`Shielding`、`Vortex`、`Waller`（OnUpdate），`Vampiric`、`Nullifier`、`Entangler`、`MirrorImage`、`StormStrider`（OnHit/OnTakeDamage），`Toxic`、`SoulEater`（OnDeath）已实现 Op 优先分发，旧处理分支保留为回退。
7. map/monster modifier_v2 的配置源以生成链路为准：`scripts/gen_map_monster_modifier_v2.py` 生成 `assets/data/modifier_v2/map_modifiers.json` 与 `assets/data/modifier_v2/monster_modifiers.json`，`build.bat` precheck 通过 `--check` 阻断漂移。

### 6.1 ECS 组件设计

```cpp
// 词缀组件
struct MonsterAffixComponent {
    std::vector<MonsterAffixType> affixes; // Enum based
    
    // 运行时状态
    float timer1 = 0.0f; // 通用计时器1
    float timer2 = 0.0f; // 通用计时器2
    bool hasUpdate = false; // 缓存标志
    bool hasOnHit = false;
    bool hasOnDeath = false;
};

// 独立机制组件 (Advanced Mechanics)
struct PhaseShieldComponent { ... }; // 处理爆发无敌逻辑
struct SoulEaterComponent { ... };   // 处理层数堆叠
```

### 6.2 性能优化
*   **SSBO Particles**: 所有的 Molten, Frozen, Toxic 地面效果必须使用 Compute Shader 粒子系统。
*   **Batching**: 同类词缀的视觉效果 (如护盾连接线) 应使用 Instanced Rendering。
