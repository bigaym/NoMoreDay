# NoMoreDay - 地图生物群落与城镇皮肤设计说明书 (V1.0)

## 1. 总体设计原则
*   **视觉风格 (Style A)**: 碎片化生态。每张地图都是漂浮在虚空中的完整世界片段，边缘采用“空气墙”机制。
*   **结构逻辑 (Style C)**: 根据主题动态调整。开阔地利于流场寻路和海量怪群；迷宫地利于走位和局部战斗。
*   **技术指标**:
    *   **空气墙 (Air Wall)**: 逻辑上的 `Wall` 属性，视觉上的透明/空洞背景。
    *   **流场寻路**: 所有怪物共享全局目标（玩家），障碍物权值为无穷大。

## 4. 技术实现指南

### 4.1 空气墙实现策略
在渲染层，如果 `TileType == Wall` 且 `Biome.UsesAirWall == true`：
*   **物理层**: 返回不可通行（Bitmask 标记为墙）。
*   **渲染层**: `DrawTexture(sky_background)` 或 `Discard` 像素，不绘制墙壁纹理，直接显示背景星空/云海。

### 4.2 敌人池权重分配
每个 Biome 关联 1-2 个 `EnemyRace`。在生成关卡时，`EnemySpawnSystem` 将根据当前 Biome 的 `enemyPool` 随机抽取相应种族的怪物实体进行实例化。

### 4.3 地形参数对照表 (JSON 参考)
```json
{
  "id": "floating_isle",
  "wallProbability": 0.42,
  "smoothIterations": 5,
  "usesAirWall": true,
  "floorColor": [100, 150, 255, 255],
  "enemyPool": ["elves", "elemental"]
}
```
