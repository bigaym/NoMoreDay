# 2D 暗黑Like Roguelite RPG - 核心战斗与角色设计 V0.1

## 1. 操作与输入模型 (Input & Control Model)

为了适应“海量敌人”和“高机动性”的战斗需求，推荐采用 **双摇杆射击 (Twin-Stick)** 风格的操作模式。

### 1.1 键鼠操作 (KBM)
- **移动 (Locomotion)**：**WASD** 控制物理移动。
- **瞄准 (Aiming)**：角色朝向始终跟随 **鼠标光标**。
- **攻击**：左键普攻，右键技能。

### 1.2 手柄/控制器 (Gamepad)
- **左摇杆 (Left Stick)**：移动角色。
- **右摇杆 (Right Stick)**：
  - 推杆方向决定瞄准方向。
  - **自动开火**：当右摇杆推到底时，自动进行普通攻击（可选项，减少手指疲劳）。
- **肩键**：RB/R1 释放技能，LB/L1 冲刺，LT/RT 交互或大招。
- **UI 交互**：必须支持十字键 (D-Pad) 在背包网格中快速移动光标。

## 2. 角色基础属性 (Character Stats)

### 2.1 经验与升级曲线 (Experience & Leveling)
- **升级机制**：杀怪掉落“经验球”（自动吸附），捡取后增加经验。
- **曲线公式**：指数增长，控制单局节奏。
  $$XP_{req} = Base \times (GrowthFactor)^{Level-1}$$
  - *Base*: 100
  - *Growth*: 1.15
  - *节奏*：前 10 级非常快（每分钟升级），20 级后显著变慢，迫使玩家依赖装备而非等级碾压。

### 2.2 核心资源 (Resources)
1.  **HP (生命值)**：
    - 归零时角色死亡，触发 Rogue 结算。
    - 不自动回复，依赖药水、吸血词条或地图掉落的“血球”。
2.  **MP (法力/能量)**：
    - 用于释放强力技能。
    - **回复机制**：
        - *方案 A*：自动缓慢回复。
        - *方案 B (推荐)*：攻击命中敌人时回复（鼓励进攻）。

### 2.2 韧性与硬直 (Poise & Stagger)
为了增加打击感，引入简化的韧性系统：
- 角色和精英怪拥有 **韧性值 (Poise)**。
- 受击时扣除韧性。
- 韧性归零 -> **破防 (Staggered)**：进入短暂眩晕状态 (0.5s) 且受到的伤害增加 20%。
- *设计目的*：防止玩家被怪群无限硬直连死，也允许玩家通过连续攻击打断 Boss 动作。

## 3. 主动技能架构 (Active Skill System)

不同于被动技能的随机获取，主动技能由 **职业** 和 **武器** 共同决定。

- **武器技能 (Weapon Skills)**：绑定在装备上。
  - 装备一把“重锤”时，左键是“横扫”，右键是“大地猛击”。
  - 装备一把“法杖”时，左键是“火球”，右键是“火墙”。
- **职业技能 (Class Skills)**：绑定在角色槽位 (Q / E / R)。
  - 例如“战士”职业自带：
    - **Q (战吼)**：恐惧周围敌人。
    - **E (旋风斩)**：消耗 MP 持续旋转。
    - **R (大招)**：天神下凡。

## 4. 战斗判定机制 (Combat Resolution)

### 4.1 碰撞检测 (Hit Detection)
鉴于同屏怪物数量巨大，严禁使用复杂的 Polygon Collider。
- **玩家**：使用圆形 Collider（半径约 15px）。
- **怪物**：
  - **移动碰撞**：圆形 Collider（用于避免重叠，使用简单的分离算法）。
  - **受击判定 (Hurtbox)**：与移动 Collider 共用，或略大一点。
- **攻击判定 (Hitbox)**：
  - **近战**：扇形或矩形检测（数学计算，非物理引擎）。
  - **投射物**：射线检测 (Raycast) 或 小圆形碰撞。

### 4.2 伤害计算公式 (Damage Formula)

采用 **乘法减伤公式**，保证后期数值不会溢出或无效。

$$FinalDamage = BaseDmg \times (1 + \sum Bonuses) \times CriticalMult \times Mitigation$$

- **减伤率 (Mitigation)**：
  $$Mitigation = \frac{100}{100 + Defense}$$
  - 举例：防御力 100 时，受到 50% 伤害；防御力 300 时，受到 25% 伤害。
  - 优点：防御力收益递减，避免无敌，无需设定防御力上限。

- **暴击 (Critical)**：
  - 判定：`Random(0, 1) < CritRate`
  - 效果：`Damage * CritDamage` (默认 150%)。

## 5. 状态效果系统 (Status Effect System)

使用统一的 **Buff/Debuff Manager** 处理持续效果。

### 数据结构
```cpp
struct StatusEffect {
    EffectType type;   // Burning, Frozen, Stun, Haste
    float duration;    // 剩余时间
    float tick_timer;  // 每一跳的计时器
    float value;       // 强度（如燃烧伤害值，减速百分比）
    EntityID source;   // 来源（用于计算击杀归属）
};
```

### 常见效果规则
- **可叠加 (Stackable)**：
  - **流血 (Bleed)**：每层独立计算时间，层数越高每秒伤害越高。
  - **中毒 (Poison)**：层数增加持续时间，不增加单跳伤害。
- **不可叠加 (Unique)**：
  - **眩晕 (Stun)**：新的眩晕会刷新持续时间，取两者的最大值，不叠加。
  - **冰冻 (Freeze)**：完全停止动画和移动。

## 6. 音效与视觉反馈 (Juiciness)

战斗手感来源于细节。

- **顿帧 (Hit Stop/Freeze Frame)**：
  - 玩家攻击命中瞬间，全局游戏暂停 3-5 帧（约 0.05秒）。
  - *仅在暴击或击中大量敌人时触发*，大幅增强打击力度感。
- **屏幕震动 (Screen Shake)**：
  - 受到伤害或造成高额伤害时，摄像机随机偏移。
- **伤害跳字 (Damage Numbers)**：
  - 普通伤害：白色，小字体，快速淡出。
  - 暴击伤害：黄色，大字体，带有弹跳动画。
  - 状态伤害：紫色/红色，向下滑动。
