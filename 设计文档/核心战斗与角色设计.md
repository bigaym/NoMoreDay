# 2D 暗黑Like Roguelite RPG - 核心战斗与角色设计 V0.5 (已重构)

## 1. 核心构建哲学 (The Build Architecture)

本项目汲取了经典 ARPG（D2, Grim Dawn, POE, Last Epoch, Titan Quest）的精髓，形成了一套三层嵌套的 Build 构建体系。

### 1.1 技能精通树 (Skill Specialization Trees)
*   **灵感来源**：*Last Epoch*
*   **机制**：每个活跃技能（Active Skill）都拥有一棵独立的精通树。
*   **深度**：玩家可以选择 5 个技能进行精通。通过投入精通点数，玩家可以改变技能的本质，例如：
    *   **形态转化**：将近战挥砍变为远程投射物。
    *   **属性转换**：将物理伤害 100% 转化为火焰伤害，并赋予相关标签。
    *   **机制加成**：增加攻击次数（Multistrike）、赋予击中触发逻辑（On-Hit Proc）。

### 1.2 虚空星盘 (The Astrolabe)
*   **灵感来源**：*Path of Exile (Passive Tree)*
*   **机制**：全局被动天赋树，负责角色的基础属性扩展和核心机制定义（Keystones）。
*   **布局**：采用圆环向外辐射的结构，中心为职业核心，外环为跨职业的通用强化。

### 1.3 标签驱动引擎 (Tag-Driven Engine)
*   **灵感来源**：*Grim Dawn / POE*
*   **核心**：系统中的所有实体（玩家、技能、怪、掉落）都由“标签（Tags）”定义。
*   **应用**：
    *   **伤害匹配**：一个具有 `[Melee, Fire, Area]` 标签的技能，会自动受到“+10% 近战伤害”和“+20% 元素伤害”的共同加成。
    *   **实时性**：标签系统是动态的，技能精通树可以在运行时实时修改技能标签。

## 2. 战斗判定与伤害流水线 (Damage Pipeline)

为了支持“亿万级”的 Build 可能性，采用了严格的加/乘分离算法。

### 2.1 伤害等级体系 (Modifier Hierarchy)
1.  **基础伤害 (Base/Flat)**：来源于武器与技能基础值。
2.  **增益加成 (Increased)**：同类型加成之间为**加法**（例如：10% Inc + 20% Inc = 30% Inc），作为基础倍率。
3.  **最终乘法 (More)**：来源于技能树或核心天赋，每条 More 修饰符均为**独立乘法**（例如：40% More x 20% More = 1.68倍）。
4.  **转化与额外 (Conversion & Gain Extra)**：遵循 `物理 -> 闪电 -> 冰霜 -> 火焰 -> 混沌 -> 虚空` 的单向转化链。

### 2.2 防御与抗性公式
*   **抗性 (Resistances)**：按百分比直接减损伤害。
    *   **抗性上限**：默认 75%，可通过天赋提升。
*   **护甲 (Armor - 动态曲线)**：
    *   针对物理伤害：`DamageMult = 100 / (100 + EffectiveArmor)`。
    *   **负面护甲 (Armor Shred)**：支持护甲穿透至负数，负护甲下伤害呈指数级增加（最高 2 倍）。

## 3. 操作与反馈模型 (Input & Juiciness)

### 3.1 操作模式
*   **混合驱动**：支持双摇杆 (Twin-Stick) 与 经典 WASD。
*   **瞄准辅助**：2D 环境下提供可选的磁力吸附瞄准，确保在海量弹幕中指向关键目标。

### 3.2 战斗手感 (Game Feel)
*   **顿帧与屏幕震动**：利用 GPU 事件同步，在造成特大暴击或击杀精英怪时触发像素级的顿帧。
*   **GPU 粒子打击感**：命中敌人时，根据伤害标签产生对应的粒子喷溅（如物理伤害喷溅血溅，雷电产生电火花），支持 200,000+ 粒子实时渲染。
*   **动态音效缓存 (Soloud/Raylib)**：根据击中单位的数量，动态压缩音效重叠强度，避免高频打击导致爆音，同时保留“拳拳到肉”的听感。

---

## 4. 资源与生命周期 (Resource Logic)

### 4.1 属性成长
*   **HP (生命值)**：核心生存资源。
*   **护盾 (Ward - 灵感自 LE)**：一种会快速衰减的临时生命值，通过攻击触发生成。
*   **能量/剑意 (Resource)**：
    *   **剑修专属：剑意 (Sword Intent)**：攻击产生剑意，剑意越高，技能范围和伤害越高。消耗剑意释放终极技能。

### 4.2 状态效果 (Ailments)
所有状态效果基于标签触发，并分为：
*   **伤害型 Ailments**：流血 (Bleed)、点燃 (Ignite)、中毒 (Poison)。
*   **控制型 Ailments**：冰冻 (Freeze)、触电/眩晕 (Shock/Stun)。

---

## 5. 职业与精通组合 (The Mastery Combination)

由于采用了 ECS 架构，支持灵活的**职业双修**系统：
*   **主职业**：决定初始星盘起始位置和基础技能。
*   **副职业 (Mastery)**：达到 25 级后，可从两个子选项中选择一个，解锁专属的主动技能和高阶精通树。
    *   *例：剑修 (Base) -> 影剑客 (Agility Focus) 或 阵剑仙 (Area Control Focus)。*
*   **属性点 (Attributes)**：力量（增伤）、敏捷（移速/暴击）、智力（资源/状态强度）。
