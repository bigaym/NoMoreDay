# NoMoreDay 开发计划与任务追踪

## 当前状态：阶段 1 - 架构重构 (Prototype -> Framework)
**核心目标**：从单文件 `main.cpp` 迁移到模块化的 ECS 架构，建立资产管理规范。

---

## 阶段 1：核心引擎架构 (Infrastructure)
- [ ] **1.1 代码结构重构**
    - [ ] 提取 `src/components/` (Common, Physics, Render)
    - [ ] 提取 `src/systems/` (PhysicsSystem, RenderSystem)
    - [ ] 实现 `src/core/Application` 类，管理主循环
- [ ] **1.2 资产管理系统 (Resource Manager)**
    - [ ] 统一加载路径规范 (`assets/textures/weapons/` 等)
    - [ ] 实现 Texture 缓存，避免重复加载
- [ ] **1.3 任务流 (Taskflow) 集成优化**
    - [ ] 将 Systems 包装为 Taskflow Modules
    - [ ] 实现更细粒度的任务并行 (如渲染准备与物理计算并行)

## 阶段 2：核心玩法原型 (MVP)

## 资产命名与存储规范 (已定稿)
- **路径**: `assets/textures/[类别]/`
- **命名**: `[类别]_[名称]_[变体].png` (例如 `weapon_sword_iron_01.png`)
- **类别**: `weapons`, `characters`, `environment`, `ui`
