# 职业设计草案：剑修 (Blade Ascendant) - 2026 深度扩展版

## 1. 职业概述 (Overview)

**剑修**是一个以高机动性、技巧性和爆发力为核心的混合型职业。他在游戏初期的表现类似传统的敏捷型战士，但随着修为（等级/天赋）提升，能够通过“御剑术”实现中远程打击和自动化攻击。

- **核心属性**: **敏捷 (Dex)** & **智力 (Int)**。
- **职业定位**: 玻璃大炮 (Glass Cannon)，高闪避，依赖机制规避伤害。
- **武器限制**: 仅限**单手剑 (1H Sword)**。禁止副手、双手武器、盾牌。

## 2. 核心机制 (Core Mechanics)

### 2.1 剑心通明 (Sword Heart) [已实现]
- **触发条件**: 仅装备单手剑，副手为空。
- **效果**:
  - **武器伤害**: 提升 **50%** (More)。
  - **格挡补偿**: 获得等同于同级盾牌的 **基础格挡几率**。
  - **法术转换**: **法术伤害** 获得等同于 **攻击伤害** 50% 的加成。

### 2.2 剑意 (Sword Intent) [已实现/待增强]
- **获取**: 近战/投射物击中时获得，上限 10 层。
- **常驻收益**: 每层提供 2% 攻速与 1% 移速。
- **状态 (Status)**: [核心功能已实现]
- **爆发机制 (Empowered Skills)**:
  - **剑压 (Sword Pressure)**: 达到 10 层时，获得 15% 额外物理穿透，且攻击附带 20% 效力的范围溅射。
  - **神通释放**: 满层时释放技能将消耗所有层数，使该技能获得 **100% 更多 (More)** 伤害并触发特殊形态。
  - **灵力共鸣**: 每消耗 1 点法力有 10% 几率产生一层剑意。

### 2.3 御剑飞行 (Sword Riding) [已实现/待优化]
**旅行模式 (Travel Mode)**:
- **触发**: 脱离战斗后连续移动 2s 进入“御剑飞行”状态。
- **效果**: 移速 +30%，无视地面陷阱（毒、火），移动动画替换为御剑浮空。
- **解除**: 受到伤害或施放攻击技能时解除状态。

**战斗模式 - 御剑步 (Sword Step)** *[需要星盘天赋: 御剑步]*:
- **触发**: 使用带有 [Movement] 标签的技能后，获得“御剑步”状态，持续 2s。
- **效果**: 移速 +20%，闪避等级 (Dodge Rating) +100，下一次攻击的暴击率增加 15%。
- **规则**: 持续时间不可叠加，但可刷新；各技能专精树中的相关节点可增强御剑步的效果或持续时间。

## 3. 技能专精树 (Skill Specialization)

### 3.0 统一约束与去同质化准则 (Design Contracts)

本章所有技能专精树遵守以下约束，用于后续实现、平衡与审查时的“合同”：

- **节点规模**：每技能专精树目标 `24-26` 节点；`2-3` 个 `<Keystone>`；至少 `1` 个 `<Synergy>`；最多 `1` 个 `<Trigger>`。
- **触发节点**：触发的技能一律使用“已专精版本”，并必须标注 `效力/内置CD/是否消耗法力`，避免链式无限触发。
- **Transmuter**：每技能最多 `2` 个、互斥；共享支持节点需对当前元素自适应（穿透/异常/减抗等按所选元素生效）。
- **剑意交互**：每棵树至少 `1` 个节点与“剑意层数/消耗/满层释放”直接交互，且在文案里显式点名。
- **范围声明**：涉及穿透/减抗/暴露/压制上限的节点，必须明确是“仅限本技能”还是“全局生效”（默认仅限本技能，除非是明确的 Buff 机制）。

#### 3.0.1 抗性削弱五型分配 (Anti-Resist Taxonomy)

为避免各技能 D 支“穿透节点”同质化，剑修 9 技能的“减抗/穿透”节点按 5 型分工：

| 类型 | 机制要点 | 分配技能 | 对应节点 |
|---|---|---|---|
| Type A: 穿透 | 无视 `X%` 抗性（仅限本技能） | 3.2 裂空斩；3.8 回旋（条件） | 灵根亲和；灵根破壁 |
| Type B: 抗性击碎 | 可叠加 debuff，降低“固定值抗性” | 3.1 流云刺；3.3 灵剑决；3.6 剑阵 | 灵根侵蚀；灵剑蚀甲；法阵侵蚀 |
| Type C: 元素暴露 | 受到对应元素伤害增加 `Y%`（不可叠加） | 3.4 剑气护体 | 元素曝光 |
| Type D: 属性转穿透 | 属性/资源 → 穿透（有上限，默认仅限本技能） | 3.5 万剑归宗（Int→穿透）；3.9 绝影（剑意→穿透） | 灵根感应；意念穿透 |
| Type E: 抗性上限压制 | 压制抗性上限（允许影响 Boss） | 3.7 心剑无影 | 心念灭抗 |

#### 3.0.2 现状评估 (2026-02-21)

- **职业背景一致性**：机动（流云刺/绝影）+ 御剑（灵剑决/万剑归宗/剑阵）+ 剑意爆发贯穿较完整，三大进阶专精的主题区分清晰。
- **同质化主要来源**：并非“机制完全重复”，而是“命名与表达重复”带来的观感同质（例如英文别名重复、节点名复用、`灵根*` 模板化命名过多）。
- **当前最需要补齐的缺口**：部分节点已满足机制分工，但仍缺少“默认仅限本技能”的范围声明；剑意交互节点在个别树中没有被文案明确标出，容易在实现/数据同步时遗漏。

#### 3.0.3 完善计划 (Next Pass)

- **Round 1：文档一致性与可实现性**：修复重复命名；统一标签/术语（穿透/减抗/暴露/上限压制）；为每个技能补一行“关键节点清单”（Keystone/Trigger/Synergy/抗性类型/剑意交互点）。
- **Round 2：实现落地对齐**：把 3.0 的合同项落入数据/脚本校验（触发环路检测、元素自适应规则、范围声明默认值）；为 9 技能各补 1-2 条平衡验收用例（数值范围、触发 CD、资源消耗边界）。

#### 3.0.4 Mastery 归属与装备偏转规则 (Affinity & Gear Pivot Contracts)

为避免进阶专精落地后反向压死 build 宽度，9 个基础技能在实现时遵守以下规则：

- **Mastery 定骨架，装备做偏转**：进阶专精决定主资源、主循环和主要爆发窗口；独特装备、传奇词缀、稀有词缀负责把单个技能从“默认职责”偏转成特殊玩法。
- **默认归属不是硬锁定**：每个技能都要标注 `默认归属专精`，但这只是无装备前提下的主推荐方向，不代表其他专精不能使用。
- **允许非主技能上位**：每个专精至少预留 `1` 条“非主技能上位”路线，供装备将原本的副技能抬成核心输出或核心循环件。
- **装备偏转边界**：装备可以改写 `资源生成方式 / 伤害形态 / 技能职责 / 触发条件`，但不应直接推翻 Mastery 的主资源身份。
- **实现优先级**：先按默认归属做出清晰可玩的 baseline build，再通过装备与后续词缀开放偏转路线。

##### 3.0.4.2 各技能的 Build 备注 (Per-Skill Build Notes)

- **`流云刺`**：默认服务剑圣的切入与连段；若后续有围绕“残影复制”“接剑返资源”“对流血目标回充能”的独特装备，允许它成为魔剑的爆发起手核。
- **`裂空斩`**：是剑圣与天剑共享度最高的技能；后续装备应优先往“单体穿透炮”“背后回响双斩”“灵剑伴飞主炮”三个方向偏转，而不是做成泛用白板强技。
- **`灵剑决`**：默认是天剑主炮台；但如果有“灵剑环身”“巨剑单体暴击”“命中回复剑流”类装备，允许剑圣拿它做副循环甚至副核。
- **`剑气护体`**：不应默认长成主输出树；它的装备偏转更适合做“反击 build”“低血收益 build”“格挡 / 偏转 build”。
- **`万剑归宗`**：默认给天剑当大范围主核；但若装备强化“引导期间以生命代替法力”“结束引导触发血爆”，它也可以成为魔剑的重火力分支。
- **`剑阵·诛仙`**：默认作为天剑站场引擎；装备可以把它改写为“脚下阵”“穿阵引爆”“处决场”，从而给魔剑或偏近战 build 使用。
- **`心剑·无影`**：默认更偏天剑 / 魔剑，因为它适合做高风险站场、元素压制或中心点处刑；后续不建议给剑圣太强的直接适配，避免三专精过度同质化。
- **`御剑·回旋`**：默认偏魔剑，因为高 hit、回手、流血、近身缠斗都很契合；但它是最值得为剑圣设计“独特装备上位路线”的技能之一。
- **`绝影绝剑`**：默认是魔剑保险阀；但通过装备把它转成“位移触发器 / 附魔窗口 / CDR 发动机”后，可以成为剑圣和天剑的重要辅助构件。

## 4. 星盘天赋布局 (Astrolabe Nodes) - 深度扩展

*设计思路：将星盘分为三个核心流派方向。*

### 4.1 凡木区 (敏捷侧)
- **[重剑无锋]**: 降低 15% 攻速，增加 40% 物理伤害，增加 50% 击退。
- **[身轻如燕]**: 移动速度的 10% 转化为闪避率。
- **[剑影步]**: 使用位移技能后，下一次受到的伤害降低 30%。
- **[百步穿杨]**: 近战武器的攻击半径增加 40%。
- **[疾风骤雨]**: 每 1% 额外移速提供 0.5% 攻击速度。
- **[残像爆发]**: 消耗剑意释放技能时，额外产生一个残影重复该动作（20% 效力）。

### 4.2 道源区 (智力侧)
- **[以气御剑]**: 你的“攻击伤害加成”现在以 80% 的效率套用于“法术伤害”。
- **[回响]**: 剑气（投射物）击中墙壁后会向最近的敌人弹射一次。
- **[灵力激荡]**: 暴击时回复 2% 的法力。
- **[万法归宗]**: 技能法力消耗降低 20%，但伤害降低 5%。
- **[剑意共鸣]**: 施放法术标签的技能时，有 20% 几率获得 1 层剑意。
- **[元素剑心]**: 你的物理伤害转换比例提升 20%（例如 50% 转火变为 70%）。

### 4.3 飞升区 (核心/混合)
- **[剑气留形] (核心)**: 使用位移技能后留下一个“残影”，残影会自动重复你下一次释放的技能（30% 效力）。
- **[御剑步] (核心)**: 使用带有 [Movement] 标签的技能后，获得“御剑步”状态 (2s)：移速 +20%，闪避等级 +100，下次攻击暴击率 +15%。处于御剑步状态时，相关技能专精树中的御剑增效节点生效。
- **[人剑合一]**: 处于御剑步或御剑飞行状态时，你的暴击率增加 50%。
- **[心剑合一]**: 智力的 50% 转化为暴击伤害 (Crit Multiplier)。
- **[御剑术·极]**: 处于御剑步状态时，[灵剑决] 的攻击频率翻倍。
- **[以血养剑]**: 你的剑意不再提供移速，改为每层提供 1% 的攻击吸血。

### 4.4 专精限定区 (Mastery Exclusive Sectors)
*仅在解锁对应专精后开放的外环区域。每个专精区默认包含：3 个基础强化节点、2 个 build 偏转节点、1 个终局型 Keystone。若未来扩充，优先在此区追加而不是回写通用区。*

#### 4.4.1 剑圣区 (Sword Saint Sector)

## 5. 进阶专精职 (Masteries)

当角色达到 50 级并完成“剑冢试炼”后，可选择一个进阶专精。专精将解锁星盘外环的专属区域，并获得独有的资源机制和招牌技能。

### 5.0 设计合同 (Mastery Design Contracts)

本章用于约束进阶专精的后续实现，避免“先做功能、后补定位”的无序扩张。

- **数量约束**: 剑修固定为 `3` 个进阶专精：`剑圣 / 天剑 / 魔剑`，当前版本不新增第四分支。
- **绑定方式**: 采用“`3 主技能 + 2~3 次级联动技能 + 其余通用技能`”的混合绑定模式，避免技能池被完全锁死。
- **主技能定义**: 每个专精必须明确 3 个核心技能，这 3 个技能承担 `资源生成 / 资源消耗 / 招牌爆发` 三种职能中的至少两种。
- **次级联动**: 每个专精可再点名 2~3 个次级技能用于防御、位移、清图或元素补完，但不得要求 9 个技能全部重做才能成型。
- **资源唯一性**: 每个专精只能新增或改写 `1` 个职业资源（剑流 / 灵剑阶 / 嗜血），不得再平行引入第二主资源。
- **招牌技能职责**: 招牌技能必须承担“构筑收束器”职责，即让玩家一眼看出该专精的胜利方式，而不是单纯更大数字的 AOE。
- **构筑识别度**: 每个专精必须回答 5 个问题：`如何起手`、`如何回资源`、`如何进爆发`、`如何保命`、`如何打 Boss`。
- **Build 宽度约束**: Mastery 负责定义 build 骨架，不负责穷尽全部变体；独特装备 / 传奇词缀 / 高价值 affix 应承担“把副技能抬成核心”与“把默认循环掰向特殊路线”的职责。
- **装备偏转要求**:
  - 每个 Mastery 至少预留 `2` 条装备驱动偏转路线。
  - 每个 Mastery 至少允许 `1` 个非主技能因装备而上位。
  - 装备可改变技能职责，但不应把专精主资源完全替换为另一套新资源。
- **防同质化约束**:
  - 剑圣不能做成“近战版天剑”；其核心是节奏、位移、暴击短窗，不依赖常驻召唤体。
  - 天剑不能做成“元素版剑圣”；其核心是远程御剑体系、元素联动、区域压制。
  - 魔剑不能做成“红色剑圣”；其核心是生命换资源、承伤换输出、吸血闭环。
- **实现优先级**: 先实现“主资源 + 招牌技能 + 3 主技能联动 + 1 条保命线”，再扩展星盘外环与更多辅助节点。

### 5.0.1 主技能 / 次级技能映射

| 专精 | 3 个主技能 | 2~3 个次级联动技能 | 备注 |
|---|---|---|---|
| **剑圣** | `流云刺` / `裂空斩` / `七星斩` | `绝影绝剑`、`御剑·回旋`、`剑气护体` | 以高频位移切入、资源爆发、决斗型单体压制为主 |
| **天剑** | `灵剑决` / `万剑归宗` / `天剑降临` | `裂空斩`、`剑阵·诛仙`、`心剑·无影` | 以远程御剑压制、元素场、频率堆叠和多来源联动为主 |
| **魔剑** | `绝影绝剑` / `御剑·回旋` / `血海` | `流云刺`、`剑气护体`、`心剑·无影` | 以低血爆发、生命成本、吸血与持续处刑为主 |

### 5.1 剑圣 (Sword Saint)
*极致的武道巅峰，以超高频率的物理打击摧毁敌人。*

- **当前实现状态 (2026-03-07)**: 已完成剑圣垂直切片（`七星斩`、`剑流` 资源/HUD、核心循环联动、专精树）。

- **定位摘要**:
  - **玩法关键词**: 决斗、连段、穿插位移、暴击爆发、短窗收割。
  - **胜利方式**: 通过高速生成和精准消耗 `剑流`，在极短时间内打出高暴击、高频多段的物理爆发，优先击穿精英和 Boss。

- **核心转化 - [剑流 (Sword Flow)]**:
  - 你的“剑意”转化为“剑流”。
  - **基础效果**: 每层提供 3% 暴击率和 2% 攻击速度，上限 10 层；不再提供移速。
  - **生成规则**:
    - 近战命中 +1。
    - 位移技能命中首个敌人额外 +1。
    - 暴击时有 20% 几率额外 +1（每 0.2 秒最多触发 1 次）。
  - **消耗规则**:
    - 仅“强化释放”或特定专精节点可主动消耗。
    - 若某技能声明“消耗全部剑流”，则按消耗层数获得额外倍率，不再额外吃基础剑意爆发，避免双重结算。
  - **设计意图**: 剑流是一个偏进攻、偏节奏、偏精确释放的资源，而非长期囤积资源。

- **主技能绑定**:
  - **[流云刺]**: 起手切入、位移追击、生成剑流，承担“进场 + 连段启动”。
  - **[裂空斩]**: 中距离补刀与消耗剑流的稳定爆发器，承担“连段续航 + 中程压制”。
  - **[七星斩]**: 终结型爆发，承担“收束器 + 决斗时刻”。

- **次级联动技能**:
  - **[绝影绝剑]**: 负责保命、重置节奏、强行再开一轮爆发。
  - **[御剑·回旋]**: 负责补单体 hit 数与回手阶段的资源维持。
  - **[剑气护体]**: 只作为轻防御和反打入口，不应成为主输出来源。

- **战斗循环**:
  - **起手**: `流云刺` 或 `破空一闪` 切入，快速建立剑流。
  - **转段**: 用 `裂空斩` / `御剑·回旋` 维持 hit 数、压缩冷却、抬暴击。
  - **爆发**: 在高剑流、御剑步、暴击窗口叠齐后释放 `七星斩` 或满层强化技能。
  - **回转**: 依靠暴击、位移、绝影重置继续循环，形成“打一轮、退半步、再打一轮”的节奏。

- **防御画像**:
  - 核心防御是 `不被打中`，不是站桩硬抗。
  - 主要保命手段来自：高位移频率、短无敌、短窗闪避提升、精准收割缩短危险战斗时间。

- **Boss 画像**:
  - 强于单体 / 精英战。
  - 对 Boss 的优势不应来自大范围清屏，而应来自“高暴击乘区 + 多段短窗 + 频繁重开输出位”。

- **招牌技能 - [七星斩 (Seven Stars Cut)]**:
  - **标签**: [Melee], [Physical], [Burst], [Invulnerable], [Mastery]
  - **描述**: 瞬间消失进入虚空，在 0.5 秒内对目标区域进行 7 次高速斩击；优先锁定精英 / Boss，期间角色处于无敌状态。
  - **冷却**: 12 秒。
  - **额外合同**:
    - 默认消耗全部剑流。
    - 每消耗 1 层剑流，单次斩击伤害总增 6%。
    - 若目标区域仅有 1 名敌人，则第 7 击自动附带处决倍率。

#### 5.1.1 [七星斩] 专精树设计锚点 (Specialization Tree Anchors)

本节先固化 `七星斩` 专精树的高层结构与核心记忆点，详细节点清单可在后续继续扩写，但不得违背以下锚点。

- **树规模目标**: `24-26` 节点，采用与现有技能树一致的完整规格。
- **中心节点规则**: 树中心为 `七星斩` 技能图标，仅承担展示、悬停说明与视觉中心作用，不提供任何数值或机制效果。
- **图结构原则**: 采用“`中心放射 + 共享前置节点群 + OR 依赖`”的结构；共享前置节点群应服务多个分支，避免单一路径线性串联。
- **基础形态**: 无专精选的 `七星斩` 为“`均衡随机斩`”——兼顾清怪与单体，不预先锁死为纯 Boss 技或纯清图技。
- **记忆点合同**: `第 7 击` 必须是技能默认就成立的核心记忆点之一，专精树负责把这最后一击推向不同 build 方向，而不是让“最后一击”仅在点出特定节点后才存在价值。
- **节点配比建议**:
  - `6-8` 个关键机制节点。
  - `10-12` 个围绕机制服务的数值节点。
  - 其余为共享前置、共享数值、风险换收益或功能偏转节点。

**[近环共享前置节点群 (Shared Entry Cluster)]**
- `星位校准`: 锁敌稳定性 / 命中判定容错 / 随机斩空修正。
- `锋芒毕露`: 基础暴击率或暴击倍率强化。
- `七曜余震`: 第 7 击的基础伤害、击退感或终结倍率强化。
- `瞬星`: 冷却、前摇 / 后摇衔接、释放节奏优化。

**[分支 A：决斗斩杀 (Duel & Execute)]**
- **职责**: 把 `七星斩` 拉向单体压制、精英处决、Boss 窗口爆发。
- **关键机制方向**:
  - `<Keystone> 七星归一`: 7 次斩击优先集中同一主目标，显著减少伤害分散。
  - `命门显现`: 前 6 击叠加破绽，第 7 击按层数结算额外倍率。
  - `破军`: 第 7 击对孤立目标 / 精英 / Boss 获得额外收益。
- **数值节点方向**: 单体增伤、最后一击暴伤、对满血或低血目标增伤、对精英 / Boss 专属倍率。

**[分支 B：剑流循环 (Sword Flow Loop)]**
- **职责**: 让 `七星斩` 成为主循环的中继站，而不是一次性大招句号。
- **关键机制方向**:
  - `流光回返`: 按命中数返还部分剑流。
  - `<Trigger> 星痕追斩`: 满层剑流释放后，结束时追加一次低效追斩 / 剑痕结算。
  - `<Keystone> 无尽七曜`: 牺牲部分瞬时爆发，换取更强的循环回报与后续技能强化。
- **数值节点方向**: 冷却恢复、命中返流概率、斩后短时增伤、位移技能恢复、下一次 `流云刺 / 裂空斩 / 御剑·回旋 / 绝影绝剑` 的强化。

**[分支 C：生存机动 (Survival & Reposition)]**
- **职责**: 强化释放安全性、落点控制、进出场容错与再切入能力。
- **关键机制方向**:
  - `踏虚`: 改善无敌时序容错与释放安全性。
  - `残星换位`: 释放结束后落到目标背后或指定侧位。
  - `<Synergy> 御剑追影`: 在 `御剑步` 状态下释放时，获得额外暴击 / 闪避 / 短时移速。
  - `<Keystone> 返星入步`: 斩击结束后立即准备下一次位移切入，形成“斩入 -> 脱离 -> 再切入”的闭环。
- **数值节点方向**: 无敌结束后的短减伤、命中后的护盾 / 回复、落点后的闪避等级、再切入位移恢复或免耗。

**[分支 D：形态改写 (Form Rewrite)]**
- **职责**: 改写技能手感与攻击覆盖方式，而不是只做数值更大的七星斩。
- **关键机制方向**:
  - `<Keystone> 天枢轮斩`: 从区域随机斩改为围绕自身或主目标的环切形态。
  - `<Keystone> 星坠`: 减少斩击次数，但提高单击重量、范围与第 7 击的重斩感。
  - `剑痕残留`: 每次斩击后留下短暂剑痕区，第 7 击的剑痕更强。
- **数值节点方向**: 范围扩大、剑痕持续时间、单击与总击数交换、对异常 / 流血 / 护甲击碎目标的额外收益。

**[成型 Build 目标]**
- `决斗处决流`: 高度聚焦单体与最后一击处决。
- `循环连段流`: 重视返剑流、斩后追击与持续重开。
- `重斩剑痕流`: 通过形态改写与残留区域获得更强清场与覆盖。

**[实现注意事项]**
- 近环共享节点应尽量允许多个外环分支以 `OR` 依赖方式接入，避免因为单一路径过深而牺牲 build 横向扩展空间。
- `七星归一` 与 `星坠` / `天枢轮斩` 等形态 Keystone 的互斥关系需要在正式节点清单中明确。
- 数值节点必须围绕机制节点服务，不应出现大量脱离玩法核心的模板化白板加成。

#### 5.1.3 [七星斩] 节点表格版 (Node Table Draft)

用于后续配表、脚本录入与实现对齐。字段约定如下：

- `类型`: `Base / Normal / Keystone / Trigger / Synergy / Transmuter`

### 5.2 天剑 (Sky Sword)
*驾驭天地灵气，将剑气化为雷霆烈火的远程炮台。*

- **当前实现状态 (2026-03-07)**: 已完成天剑垂直切片（`灵剑阶` 资源、元素亲和、`天剑降临` 领域、核心联动、专精树）。

- **定位摘要**:
  - **玩法关键词**: 灵剑群、元素转化、持续压制、领域、远程轰炸。
  - **胜利方式**: 用多来源御剑体系制造持续命中和元素压制，再以招牌技能或高频法阵完成区域歼灭。

- **核心转化 - [灵剑阶 (Sky Edge)]**:
  - 你必须选择一种元素亲和（雷 / 冰 / 火），该选择影响专精招牌技能、外环节点与默认元素表现。
  - **被动转化**:
    - 你的物理伤害的 50% 转化为选定元素伤害。
    - 你的智力改为提供元素强度与元素穿透，不再直接承担法力回复主来源。
  - **资源具象化**:
    - “剑意”不再表现为抽象层数，而是转化为 `灵剑阶`。
    - 每获得 1 层剑意，都会在身后具现 1 阶灵剑；上限 10。
    - 灵剑阶决定灵剑群的规模、法术联动频率和部分节点阈值。
  - **消耗规则**:
    - 默认情况下灵剑阶不自动消耗。
    - `天剑降临`、部分元素崩解节点、部分重构型技能可一次性消耗若干灵剑阶换取爆发。

- **主技能绑定**:
  - **[灵剑决]**: 常驻主炮台，承担“稳定命中频率 + 触发器核心”。
  - **[万剑归宗]**: 远程地毯轰炸，承担“清屏 / 领域压制 / 高阶资源倾泻”。
  - **[天剑降临]**: 招牌技能，承担“元素场收束 + 大范围爆发 + 对 Boss 建立降抗窗口”。

- **次级联动技能**:
  - **[裂空斩]**: 提供补刀、元素异常传播和中程清线。
  - **[剑阵·诛仙]**: 提供站场区域与多来源联动框架。
  - **[心剑·无影]**: 作为重火力聚怪 / 集火点，不作为必带核心。

- **战斗循环**:
  - **起手**: 先用 `灵剑决` 维持后台输出，铺出基础命中频率。
  - **建场**: `剑阵·诛仙` / `万剑归宗` 在高密度战斗区建立压制面。
  - **收束**: `天剑降临` 砸入已成型的怪群或 Boss 站位，创建降抗 / 元素场窗口。
  - **维持**: 靠灵剑群与元素异常持续扩散维持优势，形成“阵地 + 炮台 + 再轰炸”的中远程节奏。

- **防御画像**:
  - 防御来自距离、安全站位、控场和击杀前置，不来自硬吃伤害。
  - 允许用 `剑阵·诛仙` 或 `心剑·无影` 形成“安全输出区”，但不应给出与魔剑同等级的硬续航。

- **Boss 画像**:
  - 优势在持续命中、多来源叠乘、元素降抗和长窗口站场压制。
  - 不应拥有剑圣级别的贴身秒杀感，也不应拥有魔剑级别的低血换爆发容错。

- **招牌技能 - [天剑降临 (Heavenly Sword Fall)]**:
  - **标签**: [Spell], [Area], [Elemental], [Mastery], [Field]
  - **描述**: 召唤一柄巨型灵能巨剑轰击目标区域，造成巨额元素伤害，并在地面留下持续 5 秒的“灵能领域”。领域内敌人受到持续切割并降低对应元素抗性。
  - **冷却**: 15 秒。
  - **额外合同**:
    - 释放时可消耗至多 5 阶灵剑，每消耗 1 阶，扩大领域半径并提高初击伤害。
    - 领域内来自灵剑 / 万剑 / 剑阵的命中视为“同源联动”，可吃专精区的元素崩解效果。

#### 5.2.1 [天剑降临] 专精树设计锚点 (Specialization Tree Anchors)

本节先固化 `天剑降临` 专精树的高层结构与默认运转方式，详细节点清单可在后续继续扩写，但不得违背以下锚点。

- **树规模目标**: `24-26` 节点，采用与现有技能树一致的完整规格。
- **中心节点规则**: 树中心为 `天剑降临` 技能图标，仅承担展示、悬停说明与视觉中心作用，不提供任何数值或机制效果。
- **图结构原则**: 采用“`中心放射 + 共享前置节点群 + OR 依赖`”的结构；共享前置节点群应允许多个分支从不同方向接近同一核心机制。
- **基础形态**: 无专精选的 `天剑降临` 为“`初击 + 5 秒领域`”双核心技能；初击有强烈存在感，但领域不是附赠尾巴，而是默认同等重要的后续伤害来源。
- **领域基调**: 默认领域为“`持续切割场`”，适合与 `灵剑决`、`万剑归宗`、`剑阵·诛仙` 的多来源命中进行持续联动。
- **元素合同**: 基础元素表现默认继承当前 `天剑亲和元素`，不额外引入基础三元素混合形态。
- **资源合同**: `天剑降临` 默认就可消耗 `灵剑阶` 来增强初击和领域；该关系不是专精节点后置解锁内容。
- **节点配比建议**:
  - `6-8` 个关键机制节点。
  - `10-12` 个围绕机制服务的数值节点。
  - 其余为共享前置、共享数值、风险换收益或功能偏转节点。

### 5.3 魔剑 (Demon Blade)
*以血证道，放弃防御，追求极致的破坏力与恢复。*

- **当前实现状态 (2026-03-07)**: 已完成魔剑垂直切片（`血誓` 生命消耗、`嗜血` 资源、`血海` 跟随领域、核心联动、专精树）。

- **定位摘要**:
  - **玩法关键词**: 低血、血换伤、持续处刑、吸血回正、极危爆发。
  - **胜利方式**: 主动把自己压进危险线，换取更高的技能密度和伤害乘区，再通过吸血、血海和阶段性无敌 / 免死把自己拉回来。

- **核心转化 - [血誓 (Blood Oath)]**:
  - 你的所有法力消耗技能改为消耗生命值（消耗量为原法力值的 200%）。
  - **被动吸血**: 每损失 10% 生命，获得 2% 吸血。
  - **资源转化**:
    - “剑意”转化为“嗜血”。
    - 每层嗜血使你造成的伤害总增 (More) 5%，但受到的伤害增加 (Increased) 3%。
    - 上限仍为 10 层。
  - **生成规则**:
    - 消耗生命施法时，按技能生命消耗量获得嗜血。
    - 低血状态下近战命中可额外获得嗜血。
    - 吸血溢出或成功触发免死时可获得短时爆发性嗜血。
  - **设计意图**: 魔剑不是“永远满血的红色近战”，而是“主动承压、主动换血、靠回吸完成闭环”的高风险 archetype。

- **主技能绑定**:
  - **[绝影绝剑]**: 提供免死、逆脉、节奏切换，是低血玩法的保险阀。
  - **[御剑·回旋]**: 提供高 hit 数、回手期间稳定吸血与处决补刀。
  - **[血海]**: 招牌技能，承担“低血窗口的持续处刑场”。

- **次级联动技能**:
  - **[流云刺]**: 负责近身切入、收割与低血位移追击。
  - **[剑气护体]**: 负责从传统防御转为“伤害转收益”的最低防线。
  - **[心剑·无影]**: 作为站桩血雾流或空间压制流的重火力补充。

- **战斗循环**:
  - **起手**: 主动以生命施法建立嗜血层数和输出乘区。
  - **承压**: 借 `绝影绝剑` 或 `剑气护体` 进入危险但可控的低血区。
  - **爆发**: 在高嗜血、低生命、敌群密集时释放 `血海` 或 `逆脉` 组合。
  - **回正**: 靠吸血、溢出护盾、结束结算治疗把血线拉回，再决定继续贪刀还是脱战。

- **防御画像**:
  - 防御不来自稳定减伤，而来自“受伤也有收益、低血也能续命、爆发期间能反吸回来”。
  - 必须保留“会翻车”的风险感，不能做成纯数值更高的坦克。

- **Boss 画像**:
  - 对 Boss 的强项是持续缠斗和低血窗口的高压爆发。
  - 弱点应是需要贴身、需要承担高风险、对治疗抑制 / 高 burst Boss 更敏感。

- **招牌技能 - [血海 (Bloodbath)]**:
  - **标签**: [Spell], [Area], [Physical], [DoT], [Void], [Mastery]
  - **描述**: 引爆所有嗜血层数，化作跟随玩家移动的血雾领域。血雾内敌人持续受到物理 / 虚空持续伤害，并将部分伤害转化为对你的治疗。
  - **冷却**: 20 秒。
  - **额外合同**:
    - 默认消耗全部嗜血。
    - 每消耗 1 层嗜血，提高血海的半径、吸血系数或持续时间三者之一，由后续实现时择一，不三项全给。
    - 血海期间近战命中应继续与吸血 / 血爆节点联动，形成“领域内越打越不想停手”的节奏。

#### 5.3.1 [血海] 专精树设计锚点 (Specialization Tree Anchors)

本节先固化 `血海` 专精树的高层结构与默认运转方式，详细节点清单可在后续继续扩写，但不得违背以下锚点。

- **树规模目标**: `24-26` 节点，采用与现有技能树一致的完整规格。
- **中心节点规则**: 树中心为 `血海` 技能图标，仅承担展示、悬停说明与视觉中心作用，不提供任何数值或机制效果。
- **图结构原则**: 采用“`中心放射 + 共享前置节点群 + OR 依赖`”的结构；共享前置节点群应同时支持输出、续航和风险偏转三种 build 方向。
- **基础形态**: 无专精选的 `血海` 为“`跟身追猎血雾`”——血雾默认跟随角色移动，鼓励贴身缠斗，而非站桩守场。
- **基础基调**: `伤害主，治疗辅`；血海需要明显提供回正能力，但不能把魔剑的风险感洗掉。
- **资源合同**: `血海` 默认释放时清空全部 `嗜血`，该技能必须保留“开大赌命”的资源倾泻感。
- **伤害记忆点**: 基础伤害形态默认偏“`持续绞杀`”，而不是瞬时核爆或单次爆裂。
- **风险合同**: 技能本身默认不额外附带自损、承伤放大等反噬；其风险主要来自“清空嗜血后必须贴身追猎”这一战斗位置与节奏要求。
- **节点配比建议**:
  - `6-8` 个关键机制节点。
  - `10-12` 个围绕机制服务的数值节点。
  - 其余为共享前置、共享数值、风险换收益或功能偏转节点。

**[近环共享前置节点群 (Shared Entry Cluster)]**
- `血雾凝炼`: 提高血海的基础伤害密度、命中频率或覆盖稳定性。
- `猩红涌动`: 提高血海的持续时间、移动跟随稳定性或追猎手感。
- `渴血回流`: 强化血海的治疗转化、吸血结算或命中回正能力。
- `污秽侵蚀`: 强化血海附带的物理 / 虚空侵蚀、减速或压制效果。

**[分支 A：处刑绞杀 (Execution & Sustained Kill)]**

- **关键机制方向**:
  - `<Keystone> 无间血狱`: 血海内的近战 / 御剑命中会追加小额血爆，放大贴身连打收益。

### 5.4 招牌技能树设计审查 (Signature Tree Audit)

本节用于对 `七星斩 / 天剑降临 / 血海` 三棵新增招牌技能树做一轮结构审查，目标不是在此阶段继续追加节点，而是确认：`节点数量合理`、`点数路线有取舍`、`Keystone 不会同时吃满导致 build 同质化`。

#### 5.4.1 节点数量与结构审查

| 技能 | 基础核心 | 分支节点 | 总节点数 | Keystone/Transmuter | Trigger/Synergy | 结论 |
|---|---|---|---|---|---|---|
| `七星斩` | 4 | 21 | 25 | 2 Keystone + 2 Transmuter | 1 Trigger + 1 Synergy | 规模达标，结构均衡 |
| `天剑降临` | 4 | 21 | 25 | 3 Keystone | 1 Trigger + 1 Synergy | 规模达标，领域/循环/元素分工清晰 |
| `血海` | 4 | 21 | 25 | 3 Keystone + 2 Transmuter | 1 Trigger + 1 Synergy | 规模达标，输出/回正/承压分工清晰 |

- **审查结论**:
  - 三棵树都落在 `24-26` 节点目标区间内，没有出现“招牌技能比基础技能更薄”或“树体膨胀失控”的问题。
  - 三棵树均保留 `4` 个基础核心节点，能保证玩家在未深入分支前先把技能手感调顺。
  - `OR` 依赖已进入正式清单，说明 build 转向并不完全依赖单线前置，符合本轮确认的图结构目标。

#### 5.4.2 点数经济与路线取舍审查

- **点数经济目标**:
  - 玩家应能在前期点数内先做出“单一核心方向”的可玩 build。
  - 中期允许跨到第二条分支拿 1 个关键节点或 1 个功能节点。
  - 后期才允许围绕 `Keystone + 次级分支 + 形态改写` 做更完整的成型构筑。

- **建议的体验门槛**:
  - `4-6` 点：拿到基础核心 + 第一条分支的前置节点，技能开始显著偏向某种玩法。
  - `8-11` 点：拿到第一个真正定义玩法的 Keystone / Trigger / Synergy。
  - `12-16` 点：开始有余裕横向摸第二分支的功能节点，形成 build 特色。
  - `16+` 点：允许围绕主 Keystone 继续深挖，或用形态改写完成终局玩法收束。

- **具体审查判断**:
  - **`七星斩`**：`决斗斩杀` 与 `剑流循环` 两条主线都需要投入较深，适合形成“单体流”与“循环流”的明确分野；`生存机动` 和 `形态改写` 更像中后期补强而非白拿收益，取舍合理。
  - **`天剑降临`**：`坠剑镇杀`、`灵剑倾泻`、`建场共鸣` 三线各自承担不同价值，不容易出现“一条线同时给爆发、续航、控场”的超模问题；`天相改写` 更适合作为后续 build 收束器而不是开局必点线。
  - **`血海`**：`处刑绞杀`、`嗜血回正`、`追猎与承压` 天然存在明显张力；如果点数有限，玩家必须决定自己更像“杀穿型魔剑”还是“回正型魔剑”，这正是我们要的取舍。

- **当前需要持续盯住的风险**:
  - `七星斩` 的 `无尽七曜` 若后续数值给太高，可能挤压 `七星归一` 的决斗身份。
  - `天剑降临` 的 `万象轮转` 若返还效率过高，可能同时获得爆发和循环，削弱 `天穹贯星` 的存在价值。
  - `血海` 的 `饮海而生` 若回正收益过高，可能冲淡魔剑低血风险感，需严格控住“稳定感”。

#### 5.4.3 数值预算与上限约束

- **通用预算规则**:
  - 单个普通数值节点提供的无条件 `More` 伤害，建议上限控制在 `30%` 内；若是“最后一击 / 孤立目标 / Boss / 低血收割”这类强条件节点，可放宽到 `36%` 左右，但必须带条件。
  - 单棵招牌技能树内，由数值节点直接提供的 `enemy taken`、`降抗`、`返资源`、`过量治疗转护盾` 等高杠杆收益，必须有显式硬上限，不能只写“显著提高”。
  - 招牌技能的资源返还设计预算，应以“回一部分节奏”而不是“自给自足再开同一轮”为目标。

- **`七星斩` 预算约束**:
  - `命门显现` 已限制为最多 `4` 层结算，避免第 7 击在单目标上指数膨胀。
  - `流光回返 + 斗柄回天` 组合后，单次 `七星斩` 的总剑流回收硬上限为 `5` 层；长期期望值应按 `2-3` 层预算。
  - `星幕护身` 提供的临时护盾上限为 `15%` 最大生命，用于容错而非替代防御体系。

- **`天剑降临` 预算约束**:
  - 单次施放的总灵剑阶消耗上限为 `7` 阶，避免把“高持有量”直接换成过量招牌爆发。
  - `万象轮转` 单次施放最多返还 `2` 阶灵剑，定位为循环润滑而非资源永动。
  - `元素剥离` 与相关节点叠加后，由 `天剑降临` 技能树额外提供的降抗总量上限为 `12` 点。
  - 领域类 `enemy taken` 增益（如 `场域共振`）在实现时建议总上限控制在 `12%` 左右，避免与其他同源御剑增益叠乘过快。

- **`血海` 预算约束**:
  - `绝命追咬` 的持续增伤最多叠加 `3` 层，避免长时间贴身后持续伤害脱离控制。
  - `血债回生` 最多按 `5` 层嗜血计算，避免“满层开血海”同时拿满爆发和极端回正。
  - `赎罪之潮` 生成的护盾总量上限为 `20%` 最大生命，且 `饮海而生` 路线必须以牺牲伤害为前提换稳定性。
  - `鲜血回灌` 单次血海最多返还 `2` 层嗜血，保证血海结束后只能“接回一部分节奏”，不能立刻回满。
  - `血幕护身` 改为 `1 秒` 触发窗，防止高 hit 场景下变成常驻免伤引擎。

- **后续实现校验建议**:
  - 若后续装备或词缀进一步强化这些高杠杆节点，应优先套用“先有树内上限，再叠装备”的原则，而不是让装备绕开技能树上限。
  - 任何能同时提高“资源返还 + 回复/护盾 + 核心伤害”的新词缀，都必须单独过一次预算审查。

#### 5.4.4 Keystone 取舍合同

- **`七星斩`**
  - `七星归一` = 单体决斗 / Boss 处决。
  - `无尽七曜` = 斩后回接主循环。
  - `天枢轮斩 / 星坠` = 形态重写。
  - **合同**: 玩家不应轻易同时拿满“单体极限 + 循环极限 + 形态极限”；至少要放弃一边。

- **`天剑降临`**
  - `天穹贯星` = 重初击 / 重 Boss 压制。
  - `万象轮转` = 重循环 / 重灵剑阶回转。
  - `天相极化` = 重元素身份收束。
  - **合同**: `天穹贯星` 与 `万象轮转` 必须长期保持互相拉扯，不能做成“都拿最好”。

- **`血海`**
  - `无间血狱` = 近战追加血爆 / 处刑压迫。
  - `饮海而生` = 回正、吸血、结束结算。
  - `虚蚀瘴幕` = 虚空侵蚀 / 减益压制。
  - `血潮奔流 / 血环噬身` = 表现形态重写。
  - **合同**: `血海` 的 Keystone 组要体现“杀穿”“活下来”“压制场”三选一的主倾向，不应出现单一最优解。

#### 5.4.5 装备 / 传奇词缀偏转思路 (For Future Expansion)

本节只提供方向，不在本轮写死具体数值，用于后续做独特装备、传奇词缀、Boss 掉落专属词缀时参考。

- **`剑圣` 偏转思路**
  - **回旋上位**: 让 `御剑·回旋` 在接剑或回手时返还大量剑流，把它从副技能抬成主循环件。
  - **裂空决斗炮**: 让 `裂空斩` 对被 `七星斩` 标记过的目标获得高度集中化收益，形成“七星斩开窗 -> 裂空炮收束”玩法。
  - **残影流云**: 让 `流云刺` 的残影或位移连段显著参与主爆发，弱化对 `七星斩` 单按钮的依赖。

- **`天剑` 偏转思路**
  - **灵剑环身流**: 让 `灵剑决` 变得更贴身、更像环刃，而不是远程炮台，形成偏近身的异构天剑 build。
  - **定点天坠流**: 让 `天剑降临` 领域显著缩小但强度暴涨，变成极强单区处决场。
  - **剑阵炮台流**: 让 `剑阵·诛仙` 与 `天剑降临` 深度绑定，把“阵地天剑”推成主流之一。

- **`魔剑` 偏转思路**
  - **回正血海流**: 通过独特装备显著强化 `饮海而生` 路线，让魔剑变成更稳定的缠斗型 build，但要付出爆发代价。
  - **绝影血契流**: 让 `绝影绝剑` 在低血窗口中极大强化 `血海`，形成“免死 -> 血海 -> 回正”的赌命连段。
  - **引导侵蚀流**: 让 `心剑·无影` 与 `血海` 发生深联动，形成“空间压制 + 跟身追猎”的双领域魔剑。

- **跨专精通用偏转思路**
  - **资源改写型**: 改变副技能如何生成 `剑流 / 灵剑阶 / 嗜血`，但不取代主资源本身。
  - **职责改写型**: 让原本是清图技能的东西变成 Boss 技，或让原本是辅助技能的东西上位成输出核。
  - **形态锁定型**: 让某个 Transmuter / 形态 Keystone 被装备进一步深化，形成强烈身份感。
  - **同源联动型**: 奖励“招牌技能 + 主技能 + 次级技能”在短时间内连续命中同一目标的玩法。

### 5.5 三专精对比摘要

| 维度 | 剑圣 | 天剑 | 魔剑 |
|---|---|---|---|
| **主伤害形态** | 高频物理暴击 / 多段斩击 | 元素远程持续压制 / 多来源轰炸 | 低血近身爆发 / 血雾处刑 |
| **主资源** | 剑流 | 灵剑阶 | 嗜血 |
| **起手方式** | 位移切入 | 铺灵剑 / 阵地 / 轰炸 | 换血起手 |
| **主要保命** | 位移、短无敌、短窗爆发 | 距离、控场、区域压制 | 吸血、免死、低血护盾 |
| **Boss 风格** | 决斗型短窗 burst | 站场型持续压制 | 缠斗型高风险爆发 |
| **主手感** | 快、准、狠 | 稳、密、远 | 赌、狠、吸 |

### 5.6 设计落地顺序

为避免一次性扩散实现范围，建议按以下顺序落地：

1. **共通层**: 资源替换接口、招牌技能槽位、Mastery 选择 UI / 解锁状态。
2. **剑圣 MVP [已实现]**: 剑流资源、`七星斩`、`流云刺/裂空斩` 的核心联动。
3. **天剑 MVP [已实现]**: 灵剑阶资源、`天剑降临`、`灵剑决/万剑归宗` 的核心联动。
4. **魔剑 MVP [已实现]**: 血誓生命消耗、嗜血资源、`血海`、`绝影绝剑` 的保险机制。
5. **外环扩展 [部分完成]**: 4.4 专精区节点与更复杂的 build 偏转。
6. **高级耦合**: 与 Astrolabe、装备词缀、终局系统的深联动。

## 6. 技术实现路线 (Technical Roadmap)

### 6.1 共通能力建设 [主体已实现]

1. **Mastery 选择与保存**: 新增角色 50 级后的一次性专精选择、存档序列化、UI 展示、回滚保护。
2. **资源重映射框架**: 支持同一技能 / UI 槽位在不同专精下将 `剑意` 映射为 `剑流 / 灵剑阶 / 嗜血`。
3. **招牌技能框架**: 为专精招牌技能预留独立技能入口、冷却、动画和事件埋点。
4. **状态组件化**: 将“御剑步”“绝影”“领域”“招牌技能释放中”等状态转为组件标记，便于 ECS 查询与特效挂接。

### 6.2 剑圣实现需求 [MVP 已实现]

1. **无敌帧机制 (Invulnerability)**: 实现 `InvulnerableTag`，在 DamagePipeline 中直接豁免伤害，用于 `七星斩`。
2. **高频多段结算**: 支持短时间内的多段近战命中、锁敌优先级与单体处决权重。
3. **位移/冷却联动**: 支持暴击、击杀、资源消耗触发的位移技能重置与冷却缩减。

### 6.3 天剑实现需求 [MVP 已实现]

1. **灵剑实体与队列调度**: 将灵剑由纯视觉或简单攻击体升级为可被专精调度的实体 / 准实体组。
2. **Tag Conversion 增强**: 在 `DamagePipeline` 中增加稳定的元素转化、领域加成、同源联动配置。
3. **领域型招牌技能**: 支持“初击 + 持续领域 + 降抗状态”三段式技能合同。
4. **多来源命中归因**: 区分灵剑 / 万剑 / 剑阵 / 招牌技能的命中来源，便于做天剑专属联动和遥测。

### 6.4 魔剑实现需求 [MVP 已实现]

1. **生命值消耗系统**: 支持技能消耗 HP 而非 MP，并在 SkillComponent 中增加 `CostType` / `CostScale`。
2. **吸血 / 过量治疗 / 护盾转化**: 支持过量吸血转护盾、低血增吸、禁疗例外结算。
3. **危险状态保护**: 实现 `逆脉`、免死、锁血、结束结算治疗、低血触发效果的统一时序。
4. **跟随型 DoT 领域**: 支持 `血海` 这类随角色移动的范围持续伤害技能。

### 6.5 统一工程约束

1. **Damage Conversion V2**: 完善 DamagePipeline 的混合转换逻辑，支持“物理 -> 火 / 冰 / 雷 / 虚空”的专精分支扩展。
2. **遥测与验证**: 为资源生成 / 消耗、招牌技能命中、位移重置、吸血转护盾等事件加埋点，避免后续平衡失真。
3. **先做行为合同，再做大规模 VFX**: 先验证资源循环和伤害归因，再补大特效，避免返工。
