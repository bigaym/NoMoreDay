# 2D 暗黑Like Roguelite RPG - 局外成长与终局玩法 V0.2 (部分实现)

## 1. 设计哲学 (Design Philosophy)

**实现状态**: 部分实现。经验系统 (`XPAwardingSystem`) 和等级提升 (`ProgressionSystem`) 已实现，包括属性点和技能点分配。避难所系统、虚空星图等终局内容尚未实现。

- **失败并非终结**：死亡是成长的必要环节。玩家将资源带回基地，使下一次冒险更轻松。
- **自定义难度**：终局玩法应允许玩家通过承担更高风险（地图词缀）来换取更高收益。
- **知识积累**：除了数值成长，解锁图鉴、配方和剧情碎片也是重要的驱动力。

这是玩家在两局游戏之间停留的安全区域。

**实现状态**: 未实现。避难所系统尚未在代码中实现。

### 2.1 核心NPC与设施

1.  **铁匠 (The Blacksmith)**
    -   **功能**：分解装备、低级符文合成高级符文。
    -   **升级**：投入"星铁（Star Metal）"（Boss掉落材料）。
    -   **效果**：升级后解锁"定向锻造"功能，或减少锻造潜能的消耗波动。

2.  **秘术师 (The Occultist)**
    -   **功能**：洗炼词缀数值、剥离词缀（将词缀变为碎片）。
    -   **赌博 (Gamble)**：花费大量金币购买未鉴定装备（可能是垃圾，也可能是暗金）。

3.  **制图仪 (The Map Device)**
    -   **功能**：开启通往异界的传送门。
    -   **强化**：允许玩家放入"地图碎片"来增加下一次冒险的怪物密度或掉率。

4.  **储物箱 (Stash)**
    -   账号共享仓库。

## 3. 终局玩法：虚空星图 (The Void Atlas)

当玩家通关基础剧情/层数后解锁的无限模式。

**实现状态**: 未实现。虚空星图系统尚未在代码中实现。

### 3.1 节点网络 (Node Network)

- **结构**：一张由无数节点组成的网状地图。
- **迷雾**：玩家只能看到当前节点相邻的选项。
- **节点类型**：
    -   **普通节点**：标准的杀怪关卡。
    -   **精英节点**：必定包含 3+ 组精英怪，掉落稀有底材。
    -   **宝库节点**：无怪物，只有大量宝箱和陷阱。
    -   **回响节点 (Echo)**：重玩之前的某个 Boss 战，但 Boss 属性大幅强化。

### 3.2 腐化值 (Corruption)

灵感来源于 *Last Epoch*。

- **机制**：随着玩家在星图中深入，腐化值逐渐增加。
- **效果**：
    -   怪物生命/伤害：每 1 点腐化 +1%。
    -   物品稀有度/掉率：每 1 点腐化 +0.5%。
    -   **专属掉落**：某些暗金装备只有在腐化值 > 100 时才会掉落。

### 3.3 地图词缀 (Map Modifiers)

进入节点前，系统会随机生成 1-3 条词缀，玩家必须接受才能进入。

- **玩家减益**：
    -   *脆弱*：玩家护甲降低 30%。
    -   *血魔法*：技能消耗生命值而非法力。
    -   *致盲*：光照范围减半。
- **怪物增益**：
    -   *多重投射*：远程怪物额外发射 2 个投射物。
    -   *死灵*：怪物死亡后 3 秒复活一次（复活体无掉落）。
    -   *加速*：怪物移动/攻击速度 +20%。

## 4. 随从系统 (Mercenary System)

为了让单人游戏不孤单，并利用多余的装备。

**实现状态**: 未实现。随从系统尚未在代码中实现。

### 4.1 雇佣机制
- 在避难所雇佣，每次只能带一名。
- 随从死亡后，需要回城支付金币复活。

### 4.2 随从类型
1.  **圣殿骑士 (Templar)**：
    -   **定位**：坦克 / 光环工具人。
    -   **技能**：嘲讽（吸引仇恨）、治疗光环（每秒回血）。
    -   **装备栏**：单手武器、盾牌、胸甲。
2.  **斥候 (Scout)**：
    -   **定位**：远程输出 / 控制。
    -   **技能**：冰霜箭（减速）、多重射击。
    -   **装备栏**：弓/弩、头盔、皮甲。
3.  **铁狼法师 (Iron Wolf)**：
    -   **定位**：元素爆发。
    -   **技能**：闪电链、火球。
    -   **装备栏**：法杖、戒指、长袍。

### 4.3 AI 行为
直接复用 `怪物和AI设计.md` 中的行为模板：
- 圣殿骑士使用 **Tank** 模板（尝试阻挡在玩家和敌人之间）。
- 斥候使用 **Ranger** 模板（放风筝）。
