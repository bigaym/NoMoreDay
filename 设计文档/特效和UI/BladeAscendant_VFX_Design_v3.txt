## 1. 概述与风格方向

### 1.1 视觉风格：灵动水墨 (Ethereal Ink)

- **关键词**: 锋利 (Sharp)、流动 (Fluid)、残留 (Lingering)、极简 (Minimalist)
- **核心母题**:
  - **剑影残像** — 所有位移和攻击留下渐隐的半透明残影
  - **气韵流转** — 能量以水墨笔触般的曲线流动，而非硬粒子
  - **空间切痕** — 高伤害技能在屏幕空间留下可见的"切割线"
  - **虚实交替** — 蓄力→释放的视觉张力，压缩后爆发

### 1.2 色彩体系

#### 主色板 (物理/基础)

| 角色 | 色值 | 用途 |
|------|------|------|
| 主能量色 | `#9FE8FF` (天青白) | 剑气/剑意/基础天赋光效 |
| 高光 | `#FFFFFF` | 暴击闪光/命中反馈/边缘高光 |
| 阴影底色 | `#0E1318` | 水墨底纹/残影暗部 |
| 辅助色 | `#C3F8F5` (淡青) | 御剑步光韵/弱光环 |

#### 元素子色板（详见 §3）

| 元素 | 主色 | 辅色 | 粒子底色 |
|------|------|------|----------|
| 火焰 (Fire) | `#FF6B35` | `#FFC857` | `#3D1C02` |
| 冰霜 (Cold) | `#7EC8E3` | `#D4F1F9` | `#0B2545` |
| 闪电 (Lightning) | `#C77DFF` | `#E0AAFF` | `#240046` |
| 虚空 (Void) | `#5C0099` | `#9D4EDD` | `#10002B` |

### 1.3 镜头反馈规则

| 效果 | 允许范围 | 约束 |
|------|----------|------|
| 屏幕震动 (Screen Shake) | 短脉冲 `≤ 120ms`，幅度 `≤ 4px` | 仅限命中/爆发瞬间 |
| 顿帧 (Hit Stop) | `50-100ms` | 仅限 Keystone 爆发/处决 |
| 边缘晕染 (Vignette) | 静态叠加，`α ≤ 0.3` | 仅限状态持续期间 |
| 色调偏移 (Color Shift) | `≤ 15%` 饱和度变化 | 仅限 Empowered/逆脉 |
| 闪白 (Flash) | `≤ 60ms` | 禁止持续闪烁 |

## 2. 全局机制特效

### 2.1 剑意系统 (Sword Intent: 0-10 Stacks)

> ⚠️ **跳过** — 剑意积攒/巅峰/神通释放的视觉表现沿用现有渲染方案（已在 T2 `blade_ascendant_skill_rendering_integration_20260221` 中实现），不纳入本次 VFX 重设计范围。以下仅作参考记录。

#### 积攒阶段 (0-9 层)

| 层级范围 | 角色表现 | 环境表现 | UI 表现 |
|----------|----------|----------|---------|
| **0 层** | 无特殊光效 | — | 10 把剑形图标全灰 |
| **1-3 层** | 脚下淡墨旋涡 (radius 24px, α=0.15) | — | 对应图标点亮为天青白 |
| **4-6 层** | 旋涡加速 + 青色微粒上升 (8 ptc/s) | — | 图标开始微弱脉动 (sin 0.5Hz) |
| **7-9 层** | 武器锋刃光闪 (0.3Hz 脉冲) + 粒子密度×2 | 角色周围微弱气流扰动线 | 图标脉动加速 (1Hz) + 边框渐亮 |

#### 巅峰状态 (10 层 — 剑压)

- **触发瞬间**: 角色中心爆发向外扩散冲击环 (`vfx_circle_shockwave`)，duration 300ms
- **持续状态**:
  - 角色全身 Rim Light (天青白, 强度 1.5×)
  - 武器持续拖出残影轨迹 (即使静止, 通过微幅抖动模拟)
  - 脚下地面粒子被向外吹散 (GPU Particles, radial force)
- **屏幕效果**: 边缘淡青水墨晕染 Vignette (α=0.12)

#### 神通释放 (Empowered Burst — 消耗 10 层)

- **聚气** (100ms): 所有光焰瞬间向武器中心坍缩 (Reverse Shockwave)
- **释放**: 技能特效叠加以下全局增强：
  - 水墨爆裂纹理叠加 (`vfx_ink_splatter`)
  - 短暂屏幕震动 (80ms, 3px)
  - 亮度脉冲 (flash 40ms → 衰减 200ms)
- **消耗反馈**: 10 个 UI 图标依次从满到空的快速连锁消散动画 (左→右, 60ms/个)

### 2.2 御剑步 (Sword Step)

> *触发条件: 使用带 [Movement] 标签的技能后，获得 2s "御剑步"状态*

#### 激活瞬间
- 角色脚下闪现一道水平展开的流光带 (天青白, width 48px)
- 短促的上升气流粒子 (6 ptc, 向上消散)

#### 持续状态 (2s)
- 角色略微浮空 (视觉偏移 +2px，不影响判定)
- 脚下连续的淡青气韵拖尾 (Trail, α=0.2, 衰减 0.5s)
- 武器获得微弱的持续辉光边缘 (Fresnel, 天青白)

#### 消散
- 浮空状态平滑降落 (100ms ease-out)
- 气韵拖尾自然衰减消失

### 2.3 残影系统 (Afterimage — 需天赋"剑气留形")

#### 留影生成
- 在起点生成角色的半透明网格快照 (α=0.5)
- 残影初始为天青白色调，逐渐褪为墨色
- 微弱的上下浮动 (sin 0.3Hz, amplitude 1px)

#### 残影模仿
- 模仿施法时，残影播放对应技能的简化版粒子特效 (50% 粒子密度)
- 残影自身闪烁一次 (白色 flash 40ms)

#### 残影消散 (4s 后或模仿完毕)
- 自下而上的溶解效果 (Dissolve, 使用 `vfx_noise_cloud`)
- 消散时释放少量墨色碎片粒子 (4-6 ptc)

## 3. 元素视觉语言

> *当技能通过 Transmuter 节点转化元素后，整体色板和粒子行为切换为对应元素风格。*

### 3.1 物理 (Physical — 默认)

- **色板**: 天青白主色 + 白色高光 + 墨色阴影
- **粒子形态**: 锐利的线段/切痕、薄片碎片
- **光效**: 冷色调 Rim Light, 干净利落
- **特征**: 无残留地面效果、无持续区域效果

### 3.2 火焰 (Fire)

- **色板**: 橘红 `#FF6B35` → 金黄 `#FFC857` → 暗褐余烬 `#3D1C02`
- **粒子形态**: 火星飞溅 (重力下坠)、热浪扰动线、余烬漂浮
- **光效**: 暖色脉动点光源 (附加在命中点/路径上, radius 32px, 随机闪烁)
- **地面效果**: 燃烧余烬铺地 (Decal, 持续 2-3s, 边缘渐暗)
- **特征色标记**: 被点燃的敌人身上有持续的橘红色边缘光

### 3.3 冰霜 (Cold)

- **色板**: 冰蓝 `#7EC8E3` → 霜白 `#D4F1F9` → 深蓝底 `#0B2545`
- **粒子形态**: 六角冰晶碎片 (缓慢旋转下落)、霜花纹路扩展
- **光效**: 冷色恒定辉光 (无闪烁, 稳定的冰蓝光源)
- **地面效果**: 霜冻蔓延纹路 (从命中点向外扩展, 使用极坐标 UV 动画)
- **特征色标记**: 被寒冷/冻结的敌人身上有冰蓝色半透明覆盖层 + 移速降低的拖影

### 3.4 闪电 (Lightning)

- **色板**: 紫白 `#C77DFF` → 淡紫 `#E0AAFF` → 暗紫底 `#240046`
- **粒子形态**: 锯齿折线 (电弧)、细碎火花 (高速随机方向)、球形放电
- **光效**: 高频闪烁点光源 (2-4Hz 随机强度, 模拟电弧不稳定)
- **地面效果**: 感电区域有持续的微弱电弧在地面跳跃
- **特征色标记**: 被感电的敌人身上有间歇性的紫色电弧跳跃 (0.3s 间隔)

### 3.5 虚空 (Void — 仅限 3.7 心剑·无影)

- **色板**: 暗紫 `#5C0099` → 亮紫 `#9D4EDD` → 极暗底 `#10002B`
- **粒子形态**: 空间裂痕纹路 (几何碎裂线)、微型黑洞吸附线
- **光效**: "负光源" — 周围亮度被吸收降低、中心反而更暗
- **地面效果**: 空间碎裂纹路在地面闪现后消失
- **特征色标记**: 撕裂中心有持续的空间扭曲 (Distortion, 圆形区域)

## 4. 抗性削弱五型视觉分类

> *五种抗性削弱机制各有独特的视觉反馈，确保玩家能直观区分效果类型。*

### Type A: 穿透 (Penetration)

- **视觉语言**: **锐利穿透线**
- **表现**: 命中瞬间从命中点向击中方向延伸一道细长的高亮切线 (长度 16px, 持续 200ms)
- **颜色**: 纯白高光线，边缘带微弱元素色
- **适用技能**: 3.2 裂空斩 (灵根亲和)、3.8 回旋 (灵根破壁)

### Type B: 抗性击碎 (Resistance Shred)

- **视觉语言**: **破甲裂纹**
- **表现**: 目标身上出现可叠加的裂纹纹理叠加层 (最多 5-10 层可视)。每增加一层，裂纹更密/更亮。裂纹颜色跟随对应元素色。
- **颜色**: 裂纹线为对应元素色，缝隙内透出更深的元素底色
- **适用技能**: 3.1 流云刺 (灵根侵蚀)、3.3 灵剑决 (灵剑蚀甲)、3.6 剑阵 (法阵侵蚀)

### Type C: 元素暴露 (Elemental Exposure)

- **视觉语言**: **元素标记环**
- **表现**: 目标头顶出现一个对应元素色的倒三角标记 (▽)，持续闪烁表示暴露状态活跃
- **颜色**: 对应元素主色，边缘发光
- **适用技能**: 3.4 剑气护体 (元素曝光)

### Type D: 属性转穿透 (Attribute-to-Penetration)

- **视觉语言**: **能量流转线**
- **表现**: 从角色向目标之间出现细流转线 (类似虹吸线)，表示属性正在转化为穿透力
- **颜色**: 从角色端的属性色 (蓝=智力, 天青=剑意) 渐变至末端的元素色
- **适用技能**: 3.5 万剑归宗 (灵根感应: Int→穿透)、3.9 绝影 (意念穿透: 剑意→穿透)

### Type E: 抗性上限压制 (Cap Suppression)

- **视觉语言**: **压制光罩**
- **表现**: 目标被一层半透明的暗色球形光罩笼罩 (模拟"天花板被压低")，光罩从上方下压
- **颜色**: 暗紫/暗灰 + 对应元素色的细纹路
- **适用技能**: 3.7 心剑·无影 (心念灭抗)

## 5. 技能特效分解

> *每技能按以下统一结构编写：*
> - **基础形态 (Base Form)**
> - **元素变转 (Transmuter Variants)**: 路径 A / 路径 B
> - **关键节点 VFX (Key Node VFX)**: Keystone / Trigger / Synergy
> - **神通形态 (Empowered — 满层剑意释放)**
> - **并发上限与 Tier 回退**

### 5.1 流云刺 (Flowing Thrust)

*Tags: [Melee], [Movement], [Physical]*  
*Base: 向前方极速突进，路径上的敌人受物理伤害*

#### 基础形态 (Base Form)

- **起手** (Preparing, 100ms):
  - 武器锋刃高亮闪烁 (白色 flash → 天青白持续 100ms)
  - 角色脚下出现向前的蓄力气流线 (4 条, 向突进方向汇聚)
- **冲刺** (Casting):
  - **残影条带 (Trail)**: 沿路径生成平滑的天青白色带，宽度 12px，纹理 `vfx_trail_smooth`，带轻微扭曲扰动 (`distortion_normal`)
  - **残像**: 每 0.1s 生成一个半透明角色快照 (α=0.4 → α=0 over 300ms)，色调略偏蓝
  - **路径气流**: 路径两侧产生向外扩散的细线气流粒子 (4 ptc/0.1s, 向两侧消散)
- **终点** (Impact):
  - 目标点爆发十字星芒 (Cross Flare, 天青白, radius 20px, 200ms)
  - 短促冲击圈 (`vfx_circle_shockwave`, α=0.3, 100ms)

#### 元素变转 (Transmuter Variants)

**路径 A — 劫火 (Hellfire → Fire)**:
- 冲刺条带色变为橘红→金黄渐变
- 路径上铺设 **燃烧余烬** (Decal, `vfx_ember_trail`, 宽 24px, 持续 2s)
  - 余烬有微弱脉动光源 (火焰色, 随机 0.5-1Hz 闪烁)
  - 站在余烬上的敌人边缘闪烁橘红色
- 残像从蓝调变为暖橘色调
- 终点闪光变为火焰爆炸 (橘红冲击圈 + 火星飞溅 8 ptc)

**路径 B — 凛风 (Freezing Wind → Cold)**:
- 冲刺条带色变为冰蓝→霜白渐变
- 路径上留下 **霜冻轨迹** (半透明冰蓝地面纹路, 持续 1.5s)
  - 路径上的敌人脚下出现霜花扩展动画
- 残像从蓝调变为带冰晶碎片的浅蓝色调
- 终点闪光变为冰刺破裂 (冰蓝碎片 6 ptc, 缓慢下落旋转)

#### 关键节点 VFX

**`<Keystone>` 风行者 (Windwalker)**:
- 触发后角色周围爆发一圈环形气流 (风圈, 天青白, 向外扩散 200ms)
- 进入"疾风"状态: 角色持续的微弱风压线环绕 (2-3 条旋转气流线)
- 自动激活御剑步 → 叠加 §2.2 御剑步视觉

**`<Keystone>` 孤注一掷 (All In)**:
- 冲刺条带 **加粗 ×2** + 亮度提升 (bloom 强化)
- 起手蓄力改为 200ms 聚气 (武器全身高亮 + 震颤) → 必爆爆发
- 终点爆发改为更大的十字星芒 (radius ×1.5) + 屏幕震动 (60ms, 2px)
- 条带上附加 **墨痕切线** (vfx_scratch_mask, 中心黑色切痕, 模拟"一击不留")

**`<Synergy>` 影之突袭 (Shadow Strike)**:
- 当残影模仿流云刺时，残影位置发出 **半透明蓝色冲刺线** 向目标位置
- 残影自身播放简化版冲刺动画 (无残像，仅条带)

**`<Trigger>` 瞬狱影爆 (Shadow Blitz)**:
- 传送爆炸: 起点和终点各出现 **墨色圆形爆裂** (`vfx_ink_splatter`, 300ms)
- 触发裂空斩时: 从爆炸中心发射的剑气带有墨色描边 (区分主动施放)

**移形换位 (Swap — Teleport)**:
- 突进改为瞬间消失→出现 (无中间路径)
- 起点: 角色化为一团墨水碎裂消散 (Dissolve + 碎片 12 ptc)
- 终点: 角色从墨水中凝聚出现 (Reverse Dissolve, 300ms)
- 双端各引发物理范围爆炸 (冲击环 + 碎片)

#### 神通形态 (Empowered — 满层剑意释放)

- 继承 §2.1 神通释放全局增强
- 冲刺条带变为 **双层**: 内层高亮白 + 外层天青白 (宽度×1.5)
- 残像数量×2 (每 0.05s 一帧)
- 路径上留下持续 1s 的发光切痕线
- 终点爆发带 **水墨爆裂** 纹理叠加 + 更大屏幕震动 (80ms, 3px)

#### 并发上限与 Tier 回退

| 参数 | 上限 |
|------|:---:|
| Trail instances | ≤ 24 |
| Afterimage per cast | ≤ 8 |
| Path particles | ≤ 16/cast |

| Tier | 保留 | 禁用 |
|------|------|------|
| Low | 终点冲击圈 + 基础条带 | 残像、路径粒子、元素地面效果 |
| Med | +残影条带 + 2 帧残像 | 路径粒子、元素地面效果 |
| High | +完整残像 + 元素地面效果 | — |
| Ultra | +扭曲扰动 + 全屏效果 | — |

### 5.2 裂空斩 (Rending Wave)

*Tags: [Attack], [Projectile], [Physical]*  
*Base: 挥出一道穿透性的半月剑气*

#### 基础形态 (Base Form)

- **起手** (Preparing, 80ms):
  - 武器沿挥击方向发出弧形切线预示 (天青白, 半透明弧线, 60ms)
- **投射物** (Casting):
  - **新月剑波**: 弯曲的半月形网格 (Crescent Mesh)，边缘菲涅耳发光 (天青白→白色)
  - **空气扭曲**: 剑波前方附带小范围屏幕扭曲 (Distortion, radius 16px, 仅 High+)
  - **中心核**: 沿剑波中线有一条明亮的高光芯线
  - **尾迹**: 剑波后方拉出短促的残像条 (衰减 200ms)
- **命中** (Impact):
  - "玻璃破碎"碎片粒子 (8-12 ptc, 扇形扩散, 天青白薄片)
  - 短促命中十字闪光 (100ms)
- **穿透**: 穿过敌人后剑波亮度降低 20%, 体积略减

#### 元素变转 (Transmuter Variants)

**路径 A — 霜寒之刃 (Frost Form → Cold)**:
- 新月剑波色变为冰蓝→霜白渐变，边缘附带冰晶碎片尾迹

  - 起点: 墨水碎裂消散 + 方向性气流线 (向目标方向)
  - 瞬移路径: 短促的高速拖影线 (天青白, 持续 100ms)
  - 终点: 重新凝聚 + 进入绝影状态

#### 神通形态 (Empowered — 满层剑意释放)

- 不适用 (Buff/Emergency 类, 无直接剑意消耗释放)
- 但在满层剑意期间开启: 边缘光强度提升 + 退场爆发附加墨色切痕

## 6. 事件契约

### 6.1 统一事件结构

```cpp
enum class SkillVfxEventType : uint8_t {
  CastStart,          // 技能开始施放
  CastImpact,         // 命中/落地
  TriggerProc,        // Trigger 节点触发
  EmpoweredConsume,   // 消耗满层剑意释放
  BuffEnter,          // Buff/Toggle 开启
  BuffExit,           // Buff/Toggle 关闭
  TransmuterSwitch,   // 元素变转激活（新增）
  KeystoneActivate    // Keystone 形态改变（新增）
};

struct SkillVfxEvent {
  uint32_t skillId;
  uint64_t castId;
  SkillVfxEventType type;
  Vector2 origin;
  Vector2 target;
  Tag effectiveTags;          // 含元素标签的有效标签集
  uint32_t nodeRoleMask;      // Keystone/Trigger/Synergy/Transmuter bit mask
  uint8_t qualityTier;        // Low(0) / Medium(1) / High(2) / Ultra(3)
  float intensity;            // 0.0 - 1.0
  uint8_t elementType;        // 0=Physical, 1=Fire, 2=Cold, 3=Lightning, 4=Void（新增）
  uint8_t resistDebuffType;   // 0=None, 1-5=TypeA-E（新增）
};
```

### 6.2 事件生成规则

- `SkillSystem` 在 `Preparing / Casting / Settle` 关键节点发事件
- `Trigger` 节点额外发 `TriggerProc`，包含触发来源 `castId`
- 剑意满层消耗时 **必须** 发 `EmpoweredConsume`
- 元素变转激活时发 `TransmuterSwitch`（一次性，用于切换粒子模板）
- Keystone 改变技能形态时发 `KeystoneActivate`（一次性）

## 7. RenderGraph 接入规范

### 7.1 Pass 责任

| 系统 | 责任 | 写入目标 |
|------|------|----------|
| `GPUSkillEffectSystem::Update` | 事件消费、实例准备、参数上传 | SSBO 6 |
| `VFXPass` | 粒子/轨迹/技能特效绘制 | `SceneHdrColor` |
| `DistortionPass` | 屏幕空间扭曲 | `DistortionLdrColor` |

### 7.2 Owner/Resource 声明

```
VFXPass:
  Read:  SceneDepth (可选)
  Write: SceneHdrColor
  Owner: VFX

DistortionPass:
  Read:  PostProcessLdrColor
  Write: DistortionLdrColor
  Owner: Distortion
```

### 7.3 禁止项

- 禁止在技能特效路径直接写入默认 framebuffer (FBO 0)
- 禁止跳过 RenderGraph 直接改 Pass 执行顺序
- 禁止在 VFXPass 中发起新的 Compute Dispatch（必须在 `GPUSkillEffectSystem::Update` 阶段完成）

## 8. GPU 数据与 ABI 策略

### 8.1 复用优先

- `GPUSkillEffect` (SSBO 6) — 主技能特效数据
- `GPUParticle` (Compute 本地) — 粒子实例
- `GPUTrailHeader` / `GPUTrailPoint` (SSBO 10/11) — 轨迹数据
- `GPUDistortionSource` (SSBO 13) — 扭曲源
- `GPUBeamInstance` (SSBO 5) — 光束/射线实例

### 8.2 元素扩展策略

元素变转 **不新增** SSBO 结构体，通过以下方式实现：

- `GPUSkillEffect.flags` 低 4 位编码 `elementType` (0-4)
- Shader 中 `switch(elementType)` 选择对应色板和粒子行为
- 色板数据通过 Uniform 或 UBO push，不占用 SSBO binding

### 8.3 ABI 变更规则

- 若 `GPUSkillEffect` 字段不足：先做字段复用评审
- 必要时升级 `GPU_ABI_VERSION` 并更新：
  - `GPUData.hpp`
  - `tools/render_abi/abi_manifest.json`
  - `assets/shaders/generated/gpu_abi.glslinc`
- 禁止手写 GLSL ABI struct

## 9. Tier 回退矩阵

### 9.1 总体策略

| Tier | 策略 | 核心约束 |
|------|------|----------|
| **Low** | 仅保留关键判读特效 (命中/释放反馈) | 可玩性优先，禁止视觉信息丢失 |
| **Medium** | 基础 GPU 特效 + 限制并发 | 帧时间稳定优先 |
| **High** | 完整技能特效 + 元素变转 + 轻度后处理 | 平衡表现与性能 |
| **Ultra** | 完整特效 + 高品质轨迹 + 扭曲 + 全屏效果 | 受预算门控 |

### 9.2 自动回退触发顺序

```
1. 降低粒子发射率（×0.5）
2. 关闭 Distortion (扭曲)
3. 降低尾迹采样点（stride ×2）
4. 关闭次级发光层（辅色/Fresnel）
5. 禁用环境粒子（地面粒子/气流扰动）
6. 简化残影为 sprite 替代 mesh snapshot
```

### 9.3 分技能回退细则

| 技能 | Low 保留 | Medium 保留 | High+ |
|------|----------|-------------|-------|
| 3.1 流云刺 | 终点冲击圈 | +残影条带 | +气流扰动+路径粒子 |
| 3.2 裂空斩 | 发光边缘 | +新月网格 | +屏幕扭曲 |
| 3.3 灵剑决 | 灵剑本体 (减半数量) | +发射尾迹 | +完整数量+辉光 |
| 3.4 剑气护体 | 简化圆环 | +旋转剑影 | +格挡火花+Fresnel |
| 3.5 万剑归宗 | 预警圈 + 基础落剑 | +溅射粒子 | +Compute高密度+溶解 |
| 3.6 剑阵 | 法阵纹理 | +边界剑柱 | +阵内闪击+旋转动画 |
| 3.7 心剑 | 命中火花 | +射线本体 | +流动纹理+多重撕裂 |
| 3.8 回旋 | 旋转飞剑 | +回返尾迹 | +冲击环+螺旋Trail |
