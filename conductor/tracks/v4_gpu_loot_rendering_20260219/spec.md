## 1. 概述

将战利品渲染从 CPU 逐帧处理替换为 GPU 全驱动的 MDI 合批 + Compute 力导向标签避让管线，支持同屏 1000+ 战利品零 CPU 负载。

### 1.1 核心特性

| 特性 | 规格 |
|------|------|
| 合批方式 | glMultiDrawElementsIndirect 单次调用 |
| 剔除 | FrustumCullCS (BoundingSphere vs 6 Planes) |
| 标签避让 | GPU 力导向三阶段 Compute (Grid → Repulsion → Update) |
| 空间划分 | 32×32 px Cell, 原子写入 |
| 双路径 | Feature Flag `render.gpuLoot.enabled` 控制 |

## 3. GPU 力导向避让算法

### 3.1 三阶段 Compute Pipeline

```
Stage 1: GridHashCS (散列)
├── 每线程处理一个可见标签
├── 计算标签中心所在 Cell
└── atomicAdd 写入 Cell 的 labelIndices[]

Stage 2: RepulsionCS (斥力计算)
├── 每线程处理一个可见标签
├── 读取自身 Cell + 8 邻居 Cell
├── 计算斥力向量 (overlap * stiffness)
└── 写入 forceBuffer[]

Stage 3: PositionUpdateCS (位置更新)
├── labelOffset += force * damping
├── clamp 到屏幕边界
└── 仅修改显示偏移，不改逻辑坐标
```

### 3.2 关键参数（定义在 Common.hpp 或 GPUData.hpp）

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `cellSize` | 32px | 网格粒度 |
| `stiffness` | 0.5 | 弹性系数 |
| `damping` | 0.7 | 阻尼系数 |
| `minDist` | 标签高度 + 4px | 最小间距 |
| `maxIterPerFrame` | 1 | 每帧一次迭代 |
| `MAX_LABELS_PER_CELL` | 8 | Cell 容量上限 |

## 7. 验收标准

### 7.1 功能验收
- [ ] 同屏 **1000+ 战利品**标签无严重重叠（重叠面积 < 单标签面积的 10%）
