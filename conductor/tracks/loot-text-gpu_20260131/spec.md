# Specification: Loot Text GPU Instancing & Layout Optimization

**Track ID:** loot-text-gpu_20260131
**Type:** Refactor/Performance
**Created:** 2026-01-31
**Status:** Draft

## Summary

通过 GPU Instancing 技术重构掉落物文本渲染，将数百个中文字符的渲染开销从 CPU 侧的逐个提交优化为单一 Draw Call 的显卡批量处理。同时引入标签防重叠（Anti-overlap）算法，提升密集掉落时的视觉清晰度。

## Context

在《NoMoreDay》的战斗场景中，大量掉落物会导致渲染瓶颈。目前的 `DrawTextEx` 在 400 FPS 的极短帧时间内产生过高的 CPU 提交压力。我们需要利用现代 GPU 的实例化渲染能力来维持极致的帧率表现。

## User Story

作为一名对性能敏感的开发者，我希望使用 GPU 实例化来渲染掉落物标签中的每个字形，以便在海量物品掉落时游戏依然能维持 400+ FPS，且标签显示清晰、不重叠。

## Acceptance Criteria

- [ ] **性能指标**：在 100+ 掉落物场景下，`Loot Label Collection` 阶段开销 < 0.3ms。
- [ ] **渲染批处理**：全屏所有掉落物文字渲染合并为 1 次 Draw Call。
- [ ] **中文支持**：正确渲染中文字符，利用 Raylib 的 Font 纹理实现动态 UV 获取。
- [ ] **防重叠算法**：实现类似于《最后纪元》的标签布局，防止多个标签在视觉上完全重叠。
- [ ] **过滤器对接**：通过接口支持 `LootFilterResultComponent` 的颜色、缩放和可见性控制。

## Dependencies

- `RenderSystem` (核心渲染循环)
- `LabelCacheComponent` (存储预计算的文本尺寸)
- `LootFilterResultComponent` (提供过滤状态)
- `SIMDSpatialGrid` (用于辅助布局计算)

## Out of Scope

- 标签的物理掉落动画。
- 角色/怪物头顶血条的文字渲染优化（仅限战利品）。
- Loot Filter 内部逻辑的重构。

## Technical Notes

- **数据结构**：使用 SSBO 存储 `GPUGlyphInstance`，包含屏幕位置、纹理 UV 矩形和颜色。
- **布局算法**：初步考虑使用简单的 Y 轴堆叠（Vertical Stacking）或基于视口的 AABB 碰撞排斥。
- **字体获取**：需确保在 Raylib 动态扩展字体纹理（添加新汉字）时，UV 数据能实时同步。
