## 1. 概述

将 V2 的 CPU 驱动文字渲染（`PopupRenderer`）替换为 GPU 全驱动的 MSDF + Compute Shader 排版管线，消灭暴击连锁时的 CPU 瓶颈。

### 1.1 核心特性

| 特性 | 规格 |
|------|------|
| 字体技术 | Multi-Channel Signed Distance Field (MSDF) |
| 图集尺寸 | 4096×4096, RGB8, 覆盖 GB2312 + ASCII + 符号 |
| 排版方式 | Compute Shader + Warp-level prefix sum |
| 绘制方式 | MDI (glDrawArraysIndirect) |
| 动画 | GPU 端驱动（飘字/重力/淡出/缩放弹跳/暴击放大） |
| 双路径 | Feature Flag `render.gpuText.enabled` 控制 |

## 2. Data Model

### 2.1 GPUTextCommand (16 bytes, CPU → GPU)

struct GPUTextCommand {

## 3. ECS 架构

- **System**: `GPUTextSystem` — 新增系统，与 `PopupRenderer` 并存
- **交互**: 读取现有的 PopupEvent/DamageEvent，生成 `GPUTextCommand` 写入 SSBO
- **RenderGraph 位置**: 在 VFXPass 之后、UIWorld 之前（或专属 GPUTextPass slot）
- **Binding**: 使用 Pass 局部域，在 `RenderConstants` 注册新 binding

## 4. 动画系统

| 动画类型 | 算法 | flags 编码 |
|----------|------|-----------|
| 飘字上升 | `y += speed * t` | 0x00 |
| 重力下落 | `y += v0*t - 0.5*g*t²` | 0x01 |
| 淡出 | `opacity = 1.0 - smoothstep(fadeStart, duration, t)` | 0x02 |
| 缩放弹跳 | `scale = 1.0 + amp * sin(freq*t) * exp(-decay*t)` | 0x03 |
| 暴击放大 | `scale = lerp(2.0, 1.0, easeOutBack(t))` | 0x04 |

所有动画在 Compute Shader 中通过 `lifetime` 参数驱动，CPU 零介入。

## 5. 中文字形溢出策略

- **Primary Atlas**: 常用 8K 字形（高频字 + ASCII + 数字 + 符号）
- **Secondary Atlas**: 低频字形，LRU 按需加载（若需要）
- **回退**: 未命中字形使用矩形占位符 + 日志警告

## 6. Tier 策略

| Tier | 行为 |
|------|------|
| Low | CPU fallback (`PopupRenderer`) |
| Medium | GPU basic（无动画，固定淡出） |
| High | GPU full（全动画） |
| Ultra | GPU + 动画全开 + 暴击放大 |

## 7. 风险与缓解

| ID | 风险 | 缓解 |
|---|---|---|
| V4-R01 | 中文字形超出单张图集 | Primary/Secondary 双图集 + LRU |
| TEXT-R01 | MSDF 边缘在小字号下模糊 | screenPxRange 自适应调整 |
| TEXT-R02 | Compute Shader 原子竞争 | warp 级别处理，无跨 warp 原子 |

## 8. 验收标准

- [ ] GPU 文字在 High/Ultra 下视觉与 CPU `PopupRenderer` 一致
- [ ] 暴击连锁（100+ 同屏数字）性能提升 ≥ 10x vs CPU 路径
- [ ] Low/Med 自动回退 CPU 路径无异常
- [ ] GPUTextPass 帧预算 ≤ 0.15ms (极限场景)
- [ ] 中文/英文/数字/特殊符号显示正确
- [ ] Feature Flag 双路径切换无黑帧
