## 1. 概述

实现 Jump Flood Algorithm (JFA) 以 O(log N) 复杂度在 GPU 上生成 2D 距离场 (SDF)，作为辐射级联 GI 的空间跳跃加速结构。

## 2. 算法流程

```
输入: OccluderMask (R8) — 遮挡体像素=1, 空白=0

Pass 0: SeedInitCS
├── 遮挡体像素 → 写入自身坐标 (x, y)
└── 空白像素 → 写入哨兵值 (0xFFFF, 0xFFFF)

Pass 1..log₂(N): JumpFloodCS (stepSize = N/2, N/4, ..., 1)
├── 每线程读取自身 + 8 邻居（距离 = stepSize）
├── 选择最近的 seed 坐标
└── 写入输出纹理（ping-pong 双缓冲）

Pass +1: JFA补偿 (stepSize = 2, 1)
├── 额外 2 轮小步长迭代
└── 修正 JFA 已知的对角线近似误差

Final: DistanceCS
├── 从最终 seed 坐标计算欧氏距离
├── 叠加符号（遮挡体内 = 负，外 = 正）
└── 输出 R16F SDF 纹理
```

## 3. 遮挡体提取

### 3.1 OccluderExtractPass

```
遮挡体来源：
├── 静态地形：地图 chunk 碰撞层 → 提前烘焙到 OccluderMask
├── 大型障碍物：墙壁/柱子碰撞组件 → 2D 掩码投影
├── 动态遮挡体：仅关键实体（Boss 体型），按帧更新
└── 合成策略：
    ├── 静态层：仅在 chunk 加载时更新
    ├── 动态层：每帧覆写到掩码上
    └── 最终 OccluderMask = 静态 OR 动态
```

## 4. 纹理格式

| 纹理 | 格式 | 用途 |
|------|------|------|
| OccluderMask | R8 | 遮挡体掩码 |
| Seed (ping/pong) | RG16F | JFA 种子传播 |
| SDF Output | R16F | 最终距离场 |

所有纹理格式在 `RenderConstants.hpp` 注册。

## 5. 优化策略

1. **Half-res 运行**: High 档以半分辨率运行 JFA，上采样到全分辨率
2. **帧间隔更新**: 静态场景下 SDF 每 2-4 帧更新一次
3. **增量更新**: 仅动态遮挡体变化的 chunk 区域局部重算
4. **JFA+1 自适应**: 当溢出计数为 0 时跳过补偿 Pass
