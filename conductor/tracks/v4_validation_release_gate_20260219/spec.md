## 4. 契约门禁

## 5. 稳定性门禁

- [ ] 30 分钟 Ultra 档压力运行无崩溃、无显存持续增长（GPU 内存 delta < 10 MB）
- [ ] Feature Flag 双路径切换无黑帧（gpuText / gpuLoot / v4.enabled 各切换 10 次）
- [ ] Tier 自动降级无抖动（FPS 波动 < ±5 FPS 在降级触发后 3 帧内稳定）

## 6. 回退门禁

- [ ] `render.v4.enabled = false` 可完整回退到 V3（Visual regression 截图对比通过）
- [ ] 回退后 V3 全功能正常、性能不低于 V3 基线
