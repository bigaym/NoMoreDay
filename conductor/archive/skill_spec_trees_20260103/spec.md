# Specification: Blade Ascendant Skill Specialization (Flowing Thrust & Rending Wave)

## Overview
本项目旨在基于《剑修职业设计草案》，为剑修的核心技能“流云刺 (Flowing Thrust)”和“裂空斩 (Rending Wave)”实现完整的技能专精树系统。该系统将允许玩家通过分配有限的点数，深度定制技能的战斗形态、伤害类型及特殊机制。

## Functional Requirements

### 1. 专精树结构与数据
- **集中管理**：所有技能专精树的节点定义（坐标、依赖关系、数值加成、描述）统一存储在 `assets/data/skills.json`。
- **节点类型**：支持普通节点（数值加成）、关键节点（改变机制）和终极节点（质变效果）。
- **点数规则**：
    - 每个技能基础投入上限为 20 点。
    - 装备提供的额外技能等级可以突破该上限。
- **解锁逻辑**：
    - 基于连线的依赖关系。
    - 支持“至少投入 X 点前置节点”的硬性解锁要求。

### 2. 核心技能特化实现 (流云刺 - Flowing Thrust)
- **极速流/影杀流分支**：利用 `SkillHook` 系统，实现穿透敌人、残影重复冲刺、移速缩放伤害等逻辑。
- **特定机制**：
    - 消耗剑意触发的“瞬狱”或“影杀阵”逻辑。
    - 位移距离与伤害的总增缩放。

### 3. 核心技能特化实现 (裂空斩 - Rending Wave)
- **弹幕/折返分支**：实现投射物数量增加、击中/到距分裂、剑气折返（回到玩家位置）等逻辑。
- **特定机制**：
    - 基于剑意层数的暴击率/伤害缩放。
    - 磁吸力场与停留切割逻辑。

### 4. 逻辑架构
- **硬编码钩子 (Hardcoded Hooks)**：在 C++ 中通过 `SkillSpecializationSystem` 注册每个节点对应的逻辑处理函数（如 `OnProjectileCreated`, `OnHit` 等）。
- **数据同步**：确保 UI 层分配的点数能实时通过 `StatsSystem` 或 `SkillSystem` 转化为战斗中的实际增益。

## Non-Functional Requirements
- **可扩展性**：JSON 结构应能轻松支持后续其他技能（如万剑诀）的专精树添加。
- **性能**：专精逻辑的执行需保持在 ECS 系统的高效更新循环内，避免每帧分配内存。

## Acceptance Criteria
- [ ] `skills.json` 能够正确描述流云刺和裂空斩的四个分支节点。
- [ ] UI 界面能根据 JSON 数据正确渲染树形结构并处理点击加点。
- [ ] 流云刺在投入点数后，能观察到如“穿透”、“残影”等明显的机制变化。
- [ ] 裂空斩能实现“折返” logic，且受剑意层数正确缩放。
- [ ] 验证装备增加等级后的点数溢出逻辑是否生效。

## Out of Scope
- 其他剑修技能（如万剑诀、剑气护体）的具体专精实现（本次仅搭好框架，具体逻辑留待后续）。
- 技能重置（洗点）功能的 UI 交互逻辑（本次仅关注核心功能实现）。
