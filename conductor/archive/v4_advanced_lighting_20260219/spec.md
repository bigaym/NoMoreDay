## 1. 概述

将 V3 的 Clustered Lighting（256 光源基础形态）扩展为完整的 Clustered Forward+（4096 光源，多类型剔除），并引入基于全局高度场的 Raymarching 阴影、Self-Shadow 和 POM 视差遮挡。

## 2. Clustered Forward+ V4

### 2.1 从 V3 到 V4

| 维度 | V3 基础 | V4 完整 |
|------|---------|---------|
| 光源上限 | 256 | **4096** |
| 分簇维度 | tile(x,y) + layer(z) | + **类型分组** |
| 光源类型 | Point + Spot + Ambient | + **AreaLight** + **LineLight** |
| 阴影耦合 | 独立 Pass | **紧耦合** (shadow map index in light data) |
| 剔除精度 | AABB 粗筛 | + **球体精筛** + **锥体精筛** |

### 2.2 Cluster 布局

```
tile = 16×16 px
zSlices = 8
1920/16 × 1080/16 × 8 = 120 × 68 × 8 = 65,280 clusters
每 cluster: header(16B) + indices(64×4B=256B) = 272B
总计: ~17MB SSBO
```

## 3. 高度图光影系统

### 3.1 全局高度场

```
高度信息来源：
├── 地形 Tile → 基础高度（地图编辑器导出）
├── 静态物体 → 遮挡高度（障碍物、墙壁）
├── 动态实体 → 实时高度（Sprite Mask.B 通道）
└── 合成为 R16F 全局高度纹理（按 chunk 增量更新）
```

### 3.2 HeightShadowPass

- **Raymarching Shadow**: 64 steps（Ultra）/ 16 steps（High）
- **Self-Shadow**: 利用 Sprite Height Map 实现角色内部投影（8 steps）
- **软阴影**: smoothstep + 采样 Mip 自适应

### 3.3 POM (Ultra 专属)

- 视差遮挡映射：16 layers + 二分精修
- 应用于地面 Tile 和大型场景物体
- 视角过倾斜时自动关闭

## 6. 验收标准

- [ ] LightCullingPass ≤ **0.60ms**（极限场景, Ultra 4096 光源）

- [ ] 自投影在角色身上可见（手臂/武器投影到身体）
- [ ] 4096→1024→256 自动降级链路畅通，降级后 3 帧内 FPS 波动 < ±5
