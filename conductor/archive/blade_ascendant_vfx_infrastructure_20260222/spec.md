## 1. 目标 (Goal)

为「剑修技能特效统一设计文档 V3」落地一套**可执行的 VFX 基础设施**，核心诉求：

1. `SkillSystem` 发出的 `SkillVfxEvent` 能表达 **元素变转 / Keystone / 抗性削弱五型**；
2. `GPUSkillEffectSystem` 由“硬编码 switch”演进为“**配方/模板驱动**”，并复用现有 GPU 管线能力：
   - `GPUParticleSystem`（Compute 粒子）
   - `GPUTrailRenderer`（SSBO Trail）
   - `DistortionPass`（SSBO 扭曲源）
   - `VFXPass`（RenderGraph 合同内绘制到 `SceneHdrColor`）
3. QualityTier/AutoDegrade 可控：Low/Medium 不丢技能判读，高层级按预算逐步增强。

## 2. 约束 (Non-Negotiables)

来自 Quick Reference 的硬约束：

- **禁止硬编码输出到 FBO 0**（除最终合成外）。技能特效仅通过 RenderGraph 的资源与 owner 合同写入。
- **全局 SSBO binding 0-15 已满**：新增数据必须使用 Compute 本地绑定、复用已有结构或 time-slice，不新增全局 binding。
- **禁止在 `VFXPass` 内发起 Compute Dispatch**：Compute 必须在 Update 阶段完成（符合“Input→Movement→AI→Combat→SpatialGrid→Physics→Render”的帧序约束）。

## 3. 数据模型 (Data Model)

### 3.1 `SkillVfxEvent` 扩展

以 V3 设计为准，需要补齐：

- `SkillVfxEventType` 新增：
  - `TransmuterSwitch`（元素变转激活）
  - `KeystoneActivate`（Keystone 形态改变）
- `SkillVfxEvent` 新增字段：
  - `elementType`（Physical/Fire/Cold/Lightning/Void）
  - `resistDebuffType`（0=None, 1-5 TypeA-E）

兼容策略（必须在实现阶段明确）：

- 对旧事件来源提供默认值：`elementType=0`, `resistDebuffType=0`；
- `effectiveTags` 与 `nodeRoleMask` 的语义保持：模板选择以 **字段优先**（elementType/resistDebuffType）+ **Tag/RoleMask 兜底**。

### 3.2 “配方驱动”VFX 模板

新增一个运行时可加载的配置层（建议：JSON），将 `SkillVfxEvent` 映射到“VFX 配方”：

- 选择器：`skillId + eventType + elementType + resistDebuffType + nodeRoleMask`（支持通配/优先级）
- 动作集合（复用现有系统，不新增渲染入口）：
  - 粒子：调用 `GPUParticleSystem::Emit/EmitBatch`
  - 尾迹：调用 `GPUTrailRenderer::AllocateTrail/AppendPoint`
  - 叠加：写入 `GPUSkillEffect`（SSBO 6）用于 instanced quad/扇形等
  - 扭曲：通过 `GPUSkillEffectSystem` 向 `DistortionPass` 提交 distortion sources
