# Specification: UI Button Visual Polish

**Track ID:** ui-button-polish_20260131
**Type:** Feature/Refactor
**Created:** 2026-01-31
**Status:** Draft

## Summary

将新增加的按钮美术资源（主菜单按钮、冰蓝色方块/长方形按钮等）整合进现有的 UI 系统，替换目前简单的矩形渲染，提升游戏视觉质量。

## Context

项目正在进行视觉表现的系统性提升。目前 UI 按钮大多使用 `raylib` 的原始矩形填充，缺乏精致感。`UIAssetRegistry.hpp` 中已新增了一批高质量按钮素材，需要将其落地。

## User Story

作为一名玩家，我希望在点击界面按钮时能看到美观、风格统一且具有视觉反馈（如冰蓝风格）的按钮，以便获得更好的游戏沉浸感和清晰的操作反馈。

## Acceptance Criteria

- [ ] **资源加载**：确保 `UISystem` 初始化时能正确加载所有新增的按钮贴图。
- [ ] **视觉替换 - 主菜单**：`MainMenuState` 中的菜单按钮使用 `Button_Menu` 资源。
- [ ] **视觉替换 - 核心UI**：仓库（`UIStash`）、背包（`UIInventory`）等功能面板中的按钮使用 `Button_Frost_Rect` 或 `Button_Frost_Square`。
- [ ] **交互反馈**：按钮应保留或增强 Hover（悬停）效果（例如通过 `Fade` 叠加颜色）。
- [ ] **通用工具化**：在 `UIRenderer` 中封装通用的按钮绘制接口，确保文字对齐和贴图缩放一致性。

## Dependencies

- 无硬性外部依赖。
- 内部依赖 `UIRenderer` 和 `AssetLoadingSystem`。

## Out of Scope

- 不涉及新的 UI 业务逻辑。
- 不涉及按钮的复杂补间动画（由 `UIAnimationSystem` 处理）。

## Technical Notes

- 统一使用 `UIRenderer::GetScale()` 处理 DPI 适配。
- 按钮绘制应考虑贴图的九宫格（Nine-Patch）特性（如果素材支持），或简单的等比缩放。
- 考虑到性能，所有 UI 纹理应在 `UISystem::Initialize` 时完成加载。
