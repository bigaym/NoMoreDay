## 1. 概述

探索性地实现 GPU SPH (Smoothed Particle Hydrodynamics) 流体模拟，与辐射级联 GI 和距离场交互，用于血液/水面/岩浆等特效。

## 2. SPH 核心循环

```
每帧 Compute Pipeline:
├── NeighborSearchCS (空间哈希网格 → 邻居查找)
├── DensityCS (密度计算 → 压力估算)
├── ForceCS (压力梯度 + 粘性力 + 重力)
├── IntegrateCS (速度 + 位移更新, Leapfrog 积分)
└── RenderCS (粒子 → 圆形 quad / Metaball)
```

## 4. 与 GI 交互

| 交互 | 描述 |
|------|------|
| 发光注入 | 高温流体粒子（岩浆）→ Emissive Buffer 写入 |
| 遮挡注入 | 高密度液面 → OccluderMask 更新（流体遮挡 GI） |
| 光照读取 | 流体粒子颜色受 GI RadianceMap 影响 |

## 5. 空间哈希网格

复用 V4 战利品避让的 `GridHashCS` 基础设施：
- 相同的 Cell 粒度和散列策略
- 额外的 SPH 专用邻居列表（MAX_NEIGHBORS = 32）

## 6. Tier 策略

| Tier | 行为 |
|------|------|
| Low/Med/High | **Off** — 仅简化粒子特效（不做 SPH） |
| Ultra | 10K particles, 完整 SPH 管线 |

## 7. 兜底策略

1. 若 SPH 性能不达标 → 回退为纯视觉粒子（无物理交互）
2. 若 SPH 与 GI 交互导致 GI 不稳定 → 断开交互通道
3. SPH 不纳入 V5 发布门禁的强制项

## 8. 验收标准

- [ ] 10K 粒子在 Ultra 档下 SPH Pass ≤ 0.80ms
- [ ] 流体与障碍物碰撞正确（不穿模）
- [ ] 流体发光体 → Emissive Buffer 注入正确
- [ ] `render.fluid.enabled=false` 资源完全释放
- [ ] 粒子不稳定时 Leapfrog + CFL 保护不崩溃
