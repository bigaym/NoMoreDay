# Code Risk Analysis Report: VFX Consistency & Implementation Review

**Date**: 2026-01-17
**Scope**: Blade Ascendant (剑修) VFX vs [BladeAscendant_VFX_Design.md]

## Summary
目前的视觉特效系统在技术底层（尤其是基于 SDF 的 sh_skill_effect.fs）表现强劲，有效地捕捉了利落、勾边的视觉风格。然而，在**整体氛围渲染**、**高性能实例渲染**以及**反馈细节**（如扭曲效果、转折停顿）方面，代码实现与设计文档存在显著差异。多个核心视觉反馈系统目前处于已编写但被注释或简化实现的状态。

## Critical Risks (High Priority)

### 1. Performance Bottleneck in HoloBladeRenderSystem.cpp
- **Description**: 设计要求使用 **Instanced Rendering** 渲染灵剑，但目前实现为 CPU 循环遍历 + DrawTexturePro。
- **Consequence**: 在大量灵剑同屏（如满级灵剑决或多重影武者）时，Draw Calls 将呈线性增长，无法支撑 10,000+ 实体的性能目标。
- **Recommendation**: 迁移至 GPUEntitySystem 或利用 lDrawVertexArrayInstanced 进行批量渲染。

### 2. Implementation Gap in SwordIntentVisualSystem.cpp
- **Description**: 角色周身的墨迹旋涡、上升粒子和武器闪烁逻辑被完全注释掉。
- **Consequence**: 玩家在战斗中失去层数积累的力量感反馈，只有 UI 层面的变化，缺乏沉浸感。
- **Recommendation**: 重新启用系统，并按照 **2.2 (Max Stack)** 的设计添加全屏 Vignette 和空间扭曲效果。

| 特性 (Feature) | 状态 (Status) | 差异说明 (Discrepancy) |
| :--- | :--- | :--- |
| **剑意UI (10 Fly-swords)** |  Match | 实现完全符合设计，包含脉冲和最大堆叠发光。 |
| **剑压巅峰特效 (10-Stack)** |  Missing | 缺少全屏水墨晕染、空间扭曲和爆发冲击波。 |
| **流云刺残影 (Snapshots)** |  Missing | 仅有拖尾，缺少路径上的角色快照。 |
| **裂空斩扭曲 (Distortion)** |  Missing | SDF 形状正确，但缺少前方的空气扭曲和破碎粒子。 |
| **灵剑浮动 (Sine Wave)** |  Missing | 飞剑目前位移平滑，缺少待机时的上下浮动感。 |

| **万剑归宗 (Indirect Draw)** |  Missing | 目前使用普通 Projectile 逻辑，未实现 Compute Shader 粒子雨。 |

## Performance Bottlenecks
- **Draw Call Overhead**: 除了灵剑外，TrailSystem 也在每帧进行多处 lBegin/rlEnd 调用。建议改为批量几何体提交。
- **SDF Complexity**: sh_skill_effect.fs 中的分支逻辑（if-else）在旧显卡上可能有分支预测开销，建议通过 Uniform 或多 Shader 变体进行分选。

## Refactoring Suggestions
1. **实现 Snapshot System**: 增加一个通用的 VisualSnapshotComponent，在 Flowing Thrust 期间每隔 0.1s 生成一个带有 SpriteComponent 和 FadeComponent 的残留实体。
2. **集成 Distortion Pass**: 在 RenderSystem.cpp 的最后阶段（渲染 UI 前）增加一个全屏 Shader Pass，根据 SwordIntent 强度应用 fx_distortion.fs。
3. **修复 SwordIntent 氛围**: 解开 SwordIntentVisualSystem.cpp 的注释，并将层数对应的视觉参数映射到 GPUParticleSystem 的发射速率。
